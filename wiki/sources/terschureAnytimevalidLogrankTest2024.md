# The anytime-valid logrank test: error control under continuous monitoring with unlimited horizon

New England Journal of Statistics in Data Science 2(2), 190-214 (2024); ter Schure and Pérez-Ortiz share first authorship. The method was built for, and applied in, the ALL-IN meta-analysis of BCG-vaccine COVID-19 trials (ter Schure et al. 2022, medRxiv) and is implemented in the R package `safestats` (Turner et al. 2022) [terschureAnytimevalidLogrankTest2024].

## Summary
The paper defines the anytime-valid (AV) logrank test: for the two-group proportional-hazards problem H0: λ^B = θ0 λ^A versus H1: λ^B = θ λ^A with θ ≤ θ1 < θ0, the test statistic is the ratio of sequentially computed Cox partial likelihoods S^{θ1}_{θ0,t} = PL_{θ1,t}/PL_{θ0,t}, and the test rejects at any random time τ when S ≥ 1/α [terschureAnytimevalidLogrankTest2024]. Because Cox's partial likelihood is the likelihood of a sequence of multinomial draws from the risk set (sampling without replacement), each one-event factor R_{(k)} has conditional null expectation exactly 1, so S is a test martingale and Ville's inequality gives type-I error ≤ α under arbitrary stopping (Proposition 3.1), exactly and without asymptotics, for any allocation ratio. The point-alternative factor is conditionally GROW among all "generalised" AV logrank statistics (3.5) with data-dependent numerators q_{(k)}, and Appendix A.1 adds a Breiman/Wald argument that GROW approximately minimises the worst-case expected number of events to rejection. Extensions: a prequential plug-in (or Bayes-mixture) numerator for the full alternative θ ≠ θ0 and for AV confidence sequences, a Fisher-noncentral-hypergeometric version for ties (θ0 = 1 only), a Gaussian approximation S^G_k from the logrank Z-score for summary-statistics-only meta-analysis (an e-variable only for balanced allocation and 0.5 ≤ θ1 ≤ 2), a product-martingale meta-analysis across trials whose start times depend on other trials' data (Proposition 5.1), and a sketch of the full Cox model with covariates via universal inference or RIPr (Section 8.1, Appendix B). Simulations show the Gaussian AV rejection region is close to continuous-monitoring O'Brien-Fleming, the maximum (design) sample size is larger than the classical logrank test's, and the expected number of events under optional stopping is about the same or smaller [terschureAnytimevalidLogrankTest2024].

## Main results
- **Section 2, eq. (2.4)-(2.5)**: Cox partial likelihood PL_{θ,t} = ∏_{k: T(k) ≤ t} θ^{g(k)} / (ȳ^A_(k) + θ ȳ^B_(k)); at event time T(k) each i in the risk set R_(k) has event probability p_{θ,(k)}(i) = θ^{g_i}/(ȳ^A_(k) + θ ȳ^B_(k)), conditionally on the risk-set history [terschureAnytimevalidLogrankTest2024].
- **Eq. (3.1)-(3.3)**: AV logrank statistic S^{θ1}_{θ0,t} = ∏_{k: T(k) ≤ t} R_{(k)}, R_{(k)} = p_{θ1,(k)}(I(k))/p_{θ0,(k)}(I(k)); test ξ_τ = 1{S_τ ≥ 1/α}.
- **Proposition 3.1**: for any P0 with hazard ratio θ0 and any random time τ, P0{ξ_τ = 1} ≤ α. Proof: E[R_{(k)} | y_(1..k)] = Σ_{j ∈ R_(k)} p_{θ0}(j) p_{θ1}(j)/p_{θ0}(j) = 1 (eq. 3.4), so S is a test martingale w.r.t. the risk-set filtration F_(k)^- = σ(y_(1), ..., y_(k)); Ville's inequality gives P{sup_k S_(k) ≥ 1/α} ≤ α.
- **Generalised AV logrank statistic, eq. (3.5)**: S^q_{θ0,t} = ∏ q_{(k)}(I(k))/p_{θ0,(k)}(I(k)) for any predictable distributions q_{(k)} on the risk set; same guarantee for any such q.
- **Section 3.1 (GROW)**: R^{θ1}_{θ0,(k)} maximises min_{θ ≤ θ1} E_θ[ln R^q_{(k)} | y_(1..k)] over all admissible q_{(k)}, i.e. it is conditionally GROW for the one-sided alternative. Two-sided alternative (3.6) H1: θ ≤ θ1 or θ ≥ 1/θ1: use the 1/2-1/2 mixture R^{2-sided} = (R^{θ1} + R^{1/θ1})/2.
- **Appendix A.1 (Breiman / Wald identity)**: with large risk sets (i.i.d. approximation) and stopping rule τ^q = inf{t: S^q ≥ 1/α}, Wald's identity gives E_θ[N̄_τ] = E_θ[ln S^q_τ]/E_θ[ln R^q_{(1)}] ≈ (ln(1/α) + "very small")/E_θ[ln R^q_{(1)}] (eq. A.1), with the overshoot between 0 and ln|θ1/θ0|; minimising the worst-case expected number of events over q is therefore (approximately) the GROW problem [terschureAnytimevalidLogrankTest2024].
- **Section 3.2, eq. (3.7) (learning θ)**: prequential plug-in q_{(k)} = p_{θ̆_(k),(k)} with θ̆_(k) the MLE smoothed by two virtual data points p_{θ,0} = 1/(ȳ^A_0 + 1 + θ(ȳ^B_0 + 1)) × θ/(ȳ^A_0 + θ(ȳ^B_0 + 1)); gives S^{preq}. Appendix A.4: Bayes-predictive alternative S^W (eq. A.2), the method of mixtures; validity holds for any prior ("luckiness", not Bayes). Example 3.2: with θ0 = 1 and full alternative θ ≠ 1, the test is "no effect" vs "some effect" and stays valid under arbitrary violation of proportional hazards.
- **Figure 1** (m_A = m_B = 1000, θ0 = 1, design θ1 = 0.8, α = 0.05, 80% power): as the true θ falls below 0.8 the misspecified GROW S^{0.8} needs fewer events, but the oracle S^θ needs considerably fewer still; S^{preq} is worse than S^{0.8} for θ near 0.8 but better for θ < 0.6, tracking the oracle; O'Brien-Fleming needs more events than S^{0.8} as soon as θ < 0.8.
- **Section 3.3, Lemma 3.3 (ties)**: observations at pre-fixed times t_1 < t_2 < ...; conditionally on the risk sets and O_k total events, O^B_k is hypergeometric under θ = 1. S^q_{1,k} = ∏_{l ≤ k} q_l(O^B_l)/p_l(O^B_l) with predictable q_l is a test martingale, so ξ^q_{1,κ} has level α for any random observation time (proof via Doob's maximal inequality; Appendix A.3). Recommended numerator: Fisher's noncentral hypergeometric with ω = θ1, an approximation to the true alternative (whose ω_k depends on the unknown baseline hazard, Corollary A.4); accurate when inter-observation intervals are short and ties few. Null restricted to θ0 = 1 for this reason. With one event per interval it reduces to (3.1); the associated score test is the conventional tie-corrected logrank test.
- **Section 4, eq. (4.1)-(4.3) (Gaussian AV logrank)**: with Schoenfeld's (1981) asymptotic mean μ1 = log(θ1) sqrt(m_B m_A/(m_A + m_B)^2) for the logrank Z-score (limit m_A → ∞, m_B = γ m_A, k → ∞, k/m_A → 0, log θ = O((m_A + m_B)^{-1/2})), S^G_k = exp(-N̄_k μ1^2/2 + sqrt(N̄_k) μ1 Z_k); test ξ^G_K = 1{S^G_K ≥ 1/α}. Appendix C.1 (Figure 6): the increments have null expectation ≤ 1 for 1:1 allocation, but not for 2:1 or 3:1 allocation with θ1 < 1, and deviations are problematic outside 0.5 ≤ θ1 ≤ 2; Appendix C.2 (Figure 7): under continuous monitoring τ^G = τ in most cases and otherwise the Gaussian test is more conservative.
- **Section 4.1 (rejection regions)**: for m_A = m_B the Gaussian AV test rejects when Z_n ≤ sqrt(n)/4 ln(θ1) − sqrt(2/n) log(α)/log(θ1) (θ1 < 1), while continuous-monitoring O'Brien-Fleming rejects when Z_n ≤ −sqrt(n_max/n) q_{1−α/2}; both are more conservative early (Figure 2). Design for θ1 = 0.7, 80% power, α = 0.05: fixed-sample logrank needs 195 events, O'Brien-Fleming 205, Pocock (10 looks) 245. Figure 3: AV test can continue past n_max to approach 100% power; two null paths rejected by O'Brien-Fleming are not rejected by the AV test.
- **Proposition 5.1 (meta-analysis / optional continuation)**: for k_E experiments on independent populations with start times V_(k) depending only on data of the experiments already running, S^{meta}_{θ0,t} = ∏_i S^i_{θ0,t} (with S^i = 1 before V_(i)) is a test martingale w.r.t. the joint filtration, so 1{S^{meta}_τ ≥ 1/α} has level α for any random time τ. Proof by reduction to independent left truncation in the sense of Andersen et al. (1993) (Appendix A.2). Neither the number of trials nor n_max per trial need be fixed; interim results of ongoing trials can be multiplied.
- **Section 6 (AV confidence sequences)**: CI_t = smallest interval containing all θ0 with S^{preq}_{θ0,t} ≤ 1/α (eq. 6.1 definition P_θ{θ ∉ CI_t for some t} ≤ α), valid by Ville's inequality; works for any S^q. Section 8.4: inverting the point-alternative S^{θ1}_{θ0,t} instead can give intervals that stay wide forever.
- **Section 7, Figure 4 (power and sample size, α = 0.05, 80% power, θ0 = 1, data generated at θ = θ1)**: classical logrank sizes n(0.1) = 5, n(0.2) = 10, n(0.3) = 18, n(0.4) = 30, n(0.5) = 52, n(0.6) = 95, n(0.7) = 195, n(0.8) = 497, n(0.9) = 2228 (Schoenfeld n = 4(z_α + z_β)^2/log^2 θ1). AV tests need a larger maximum n_max (the (1−β)-quantile of τ^q, Appendix A.5) but, with the rule "stop at S ≥ 20 or n = n_max", a mean number of events about equal to or noticeably below the fixed-sample size for θ1 ≥ 0.3; the conditional mean given rejection is smaller still. For θ1 = 0.1 Schoenfeld's formula gives 5 events but simulation shows 6-7 are needed; the classical and O'Brien-Fleming tests lack type-I control there.
- **Section 8.1 / eq. (8.1)-(8.2) and Appendix B (covariates)**: partial likelihood p_{β,θ,(k)}(i) = exp(<β, z^i_(k)> + g_i β_θ)/Σ_{j ∈ R_(k)} exp(...); composite null H0: β ∈ R^d, θ = 1. Universal inference: denominator uses the running MLE β̂(k_t) of the events strictly before t (eq. 8.2); easy to implement, power suspect unless d is small relative to events (Tse and Davison 2022). Theorem B.1 (corollary of Theorem 1 of grunwaldSafeTesting2024): with q_{W,θ,(k)} = ∫ p_{β,θ,(k)} dW(β) and q^←_{W,θ0,(k)} its RIPr onto {q_{W',θ0,(k)}: W' in a convex set W°}, R^{θ1}_{W,θ0,(k)} = q_{W,θ1,(k)}(I(k))/q^←_{W,θ0,(k)}(I(k)) is a conditional e-variable under every (β, θ0), for any prior W (including the running posterior W_{k+1}); the RIPr prior has finite support when the risk-set process has finite range. Appendix B.2: Li-Barron algorithm gives O(ln(1/δ)/M) approximation after M steps when priors are restricted to min_i q_{W,θ0}(i) ≥ δ; whether it is practical for Cox is future work. Appendix B.3: ties with covariates are hard; recommend worst-case ordering of tied events.
- **Section 8.2 (staggered entry)**: martingale property generally fails under staggered entry on patient time (Sellke and Siegmund 1983; Slud 1984); no problem on a common calendar time scale (left truncation) or when entries come in large stratifiable groups.
- **Section 8.3 ("your trial is not doomed")**: any AV trial can be extended, so low conditional power never dooms a trial; follow-up can be extended without new recruitment.
- **Section 8.4 (recommendations)**: use S^{θ1}_{θ0,t} when a one-sided minimal clinically relevant θ1 is given and proportional hazards is believed (GROW, minimal worst-case expected stopping time); use S^{preq} for the full alternative, under suspected misspecification, or whenever shrinking AV confidence sequences are wanted (COVID vaccine example: 50% efficacy as design alternative, data suggested > 80%); use the Gaussian version only when only Z-statistics are available and only in the validated regime.

## Setting and assumptions
- Data: m participants with (X_i, g_i, δ_i), X_i = min(T_i, C_i); event and censoring times independent with continuous distributions (no ties in the main construction); all members of a group share a hazard; null H0: λ^B_t = θ0 λ^A_t for all t, alternative λ^B_t = θ λ^A_t with θ ≤ θ1 < θ0 (one-sided), two-sided (3.6), or full θ ≠ θ0; baseline hazard λ^A nonparametric and unknown.
- Validity is exact and nonasymptotic, for any allocation m_A : m_B, and under general independent incomplete-observation patterns (independent censoring, left truncation, filtering) because these preserve the compensator structure dA^i_t = y^i_t dλ^i_t (Appendix A.2, Lemma A.1, Corollary A.2, via Andersen et al. 1993, III.4). Continuous-time filtration F_t = σ(N^j_s: s ≤ t); the test martingale factors correspond to events (patients leaving), not arrivals.
- Optional stopping: allowed at arbitrary random times τ (Proposition 3.1); optional continuation across trials: allowed when all trials test the same global null and start times depend only on data of other trials (Proposition 5.1).
- Type-I error does not depend on the alternative being well specified; GROW optimality and the Breiman expected-stopping-time argument do (large risk sets, i.i.d. approximation, negligible chance of exhausting the data).
- Ties: observation times fixed in advance, no censoring (or censoring after the events in each interval), θ0 = 1 only.
- Gaussian approximation: Schoenfeld regime, balanced allocation, 0.5 ≤ θ1 ≤ 2; not an e-variable otherwise. Simulations: 10^4 survival-process realisations per setting, nmax as (1−β)-quantile of τ^q, bootstrap error bars negligible (Appendix A.5).

## Open questions / gaps
- Full Cox model with covariates: does the Li-Barron algorithm make the sequential RIPr e-variable (Theorem B.1) computable in practice, and how does it compare in power with the universal-inference running-MLE version (eq. 8.2)? Stated as a major goal for future work (Section 8.1, Appendix B.2).
- Ties with covariates: no known e-variable-preserving approximation of the noncentral hypergeometric partial likelihood (Peto 1972; Efron 1977); worst-case ordering recommended meanwhile (Appendix B.3).
- Ties without covariates: an exact GROW numerator for θ1 ≠ 1 requires the baseline hazard; only the ω ≈ θ1 approximation is given, and only θ0 = 1 is handled (Section 3.3, Appendix A.3).
- Staggered entry on patient time: which scenarios preserve full anytime validity is open (Section 8.2).
- Rigorous justification of the sequential Gaussian approximation (possibly via time-uniform CLT, Waudby-Smith et al. 2021) instead of simulation (Appendix C).
- No prior is known for which the Bayes-mixture numerator (A.2) is analytic; Gibbs sampling suggested (Appendix A.4).
- Comparison of expected stopping times is approximate (overshoot ignored, i.i.d. risk-set approximation); the exact min-max stopping-time optimality of GROW in the finite-risk-set setting is not proved (Appendix A.1).
