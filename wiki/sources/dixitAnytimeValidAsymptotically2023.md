# Anytime valid and asymptotically optimal inference driven by predictive recursion

## Summary
The paper builds an [e-process](../concepts/e-process.md) for a composite null P0 against a nonparametric mixture alternative by taking the running-maximum-likelihood form of [universal inference](../concepts/universal-inference.md) (no data splitting) and filling the numerator with the joint marginal density produced as a by-product of Newton's predictive recursion (PR) algorithm [dixitAnytimeValidAsymptotically2023, eq. 6]. PR updates a mixing-distribution estimate Ψ̂_i by a stochastic-approximation step with weights w_i = (i + 1)^{−γ}, so the one-step-ahead predictive density q̂_{X^{i−1}}(X_i) is nonanticipating and the product of these predictives, "à la Wald (1947, eq. 10.10), Dawid (1984), Rissanen (1984)", is a bona fide joint density [dixitAnytimeValidAsymptotically2023, eqs 4–5]. The resulting PRe-process E^pr_n = q̂^pr(X^n) / sup_{P0} p(X^n) is dominated, for each fixed null P0, by a likelihood-ratio [test martingale](../concepts/test-martingale.md), so it is an e-process and tests at threshold 1/α are anytime valid (Theorem 1, Corollary 1). Under PR's standard consistency conditions and a mild condition on the null MLE, log E^pr_n ≥ n{κ*(P0) − K(P*, Q)} + o(n) almost surely, where typically κ*(P0) = K(P*, P0) and Q is the convex hull of the kernels; this is the first-order growth rate that the oracle e-process with the true density p* on top would achieve, so the PRe-process is first-order asymptotically optimal in the Cover–Thomas sense (Theorem 2). The o(n) gap to the oracle is exactly Σ_i log{p*(X_i)/q̂_{X^{i−1}}(X_i)}, bounded by n^{2/3} from Martin–Tokdar's PR rate and conjectured, with simulation support, to be about n^{1/3} [dixitAnytimeValidAsymptotically2023, Sec. 3.3, Supp. E]. Illustrations cover testing monotonicity (Grenander MLE vs gamma mixtures), a von Mises–Fisher null vs its mixtures, log-concavity (where it beats Dunn et al.'s split UI by about a factor two in slope and matches Gangrade et al.'s kernel-UI with lower variance and genuinely recursive updates), and time homogeneity of binary series [dixitAnytimeValidAsymptotically2023, Secs 4–5].

## Main results
- **Construction, eq. (6)**: E^pr_n = q̂^pr(X^n) / sup_{p ∈ P0} p(X^n), with q̂^pr(X^n) = Π_{i=1}^n q̂_{X^{i−1}}(X_i) the product of PR's one-step-ahead predictives (eq. 5); each update Ψ̂_n → Ψ̂_{n+1} is O(1) in n versus O(n) for a nonanticipating MLE refit.
- **Theorem 1**: for iid data and any P0 ⊂ P, (E^pr_n) is an e-process. Proof: E^pr_n ≤ q̂^pr(X^n)/p0(X^n) for every P0 ∈ P0, and the right side is a test martingale under P0.
- **Corollary 1**: the test rejecting when E^pr_n ≥ 1/α has sup_{P0} P0{T_α(X^N) rejects} ≤ α for every stopping rule N (Ville).
- **Eq. (7) (Martin and Tokdar 2011)**: n^{−1} log q̂^pr(X^n) = n^{−1} log p*(X^n) − K(P*, Q) + o(1) P*-a.s., with K(P*, Q) = inf_{Q ∈ Q} K(P*, Q) and Q = co{P_u : u ∈ U}.
- **Eq. (9)**: define κ*(P0) by liminf n^{−1} log{p*(X^n)/p̂0(X^n)} ≥ κ*(P0); always κ*(P0) ≤ K(P*, P0), with equality in the "typical" case that the null MLE is consistent for the KL projection P0†.
- **Theorem 2**: if (7) and (9) hold then log E^pr_n ≥ n Δ(P*; P0, Q) + o(n) P*-a.s., with Δ = κ*(P0) − K(P*, Q) (eq. 10). When K(P*, P0) > K(P*, Q) the e-process grows exponentially; when K(P*, P0) < K(P*, Q) (in particular when the null is true) and (9) holds with "lim" and "=", it vanishes; in the edge case of equality nothing is claimed.
- **Optimality claim, Sec. 3.3**: with the null MLE fixed in the denominator, no numerator confined to Q can beat (10) to first order; the Safe Testing GRO e-variable with the true P* in its numerator has the same first-order rate, so the PRe-process is first-order optimal relative to its mixture model.
- **Oracle gap, Sec. 3.3 and Supp. D–E**: log E^or_n − log E^pr_n = Σ log{p*(X_i)/q̂_{X^{i−1}}(X_i)} ≍ n K(p*, q̂_{X^n}); Martin–Tokdar give n^{1−γ} K(p*, q̂_{X^n}) → 0 for γ ∈ (2/3, 1] and P* interior to Q, so the gap is conservatively n^{2/3} at γ ≈ 2/3. Proposition 1 (Supp. D) strengthens this to n^{1−γ} max_{s ≥ n} K(p*, q̂_{X^s}) → 0 via Robbins–Siegmund's maximal inequality for almost supermartingales. Simulation (Supp. E, Gaussian location mixtures, 250 replicates, n up to 30 000): fitted exponent 0.325 (s.e. 0.002) for interior P*, 0.545 (s.e. 0.008) for boundary P*; the conjecture n^{γ/2} ≈ n^{1/3} is supported. Choosing γ = 0.51 instead of 0.67 made the gap larger, against intuition.
- **Supp. B**: anytime p-value π^pr = 1 ∧ 1/E^pr_n; inverting over singleton nulls gives an anytime-valid confidence set C_α(X^n) = {φ(P) : π^pr(X^n; {P}) > α} for any functional φ, and a possibility-measure "inferential model" for imprecise-probabilistic uncertainty quantification.
- **Supp. C**: Conditions 1–4 (compact U with continuous kernel; Σ w_i = ∞, Σ w_i² < ∞; sup_{u1,u2} ∫ (p_{u1}/p_{u2})² p* < ∞; ∫ (log p*/q*)² p* < ∞ for the KL projection q*) and a proof of (7) via Teicher's martingale strong law; the Neyman–Scott example shows κ*(P0) < K(P*, P0) is possible when the null MLE is inconsistent: with J observations per mean, σ̂² → (J − 1)σ²/J and n^{−1} log{p*(X^n)/p̂0(X^n)} → log((J − 1)/J) < 0 although the model is correctly specified and the minimal KL is 0.
- **Sec. 5.1, log-concavity**: against P* = uneven two-component normal mixture (means 0 and μ ∈ {6, 10, 14}, variance 2), the PRe-process slope is faster than Dunn et al.'s split-UI E^ui (whose slope is roughly half, attributed to 50–50 splitting) and no slower than Gangrade et al.'s running-KDE E^ulr, with markedly smaller variance; Supp. F repeats this at d = 3 with a particle-filter PR, where the PRe-process is closer to the oracle and far less variable than the kernel-UI e-process.
- **Sec. 5.2, time homogeneity**: binary series of length T = 15, Bernoulli null with per-series ω_i vs a PR-fitted mixture of two-state Markov kernels indexed by (u00, u11) ∈ [0, 1]²; log E^pr falls rapidly under the null and rises rapidly under the alternative for n = 20, ..., 200.
- **Supp. G**: an alternative "recursive Bayes predictive" e-process built from Hahn, Martin and Walker's copula-based density recursion, which needs no mixture kernel; no theory yet.

## Setting and assumptions
- Data iid from an unknown P*; null a composite P0 ⊂ P with a computable (or boundable) maximum likelihood p̂0(X^n); alternative implicitly the convex hull Q of a user-chosen kernel family {P_u : u ∈ U} with U compact (a grid or particle approximation in practice). Validity (Theorem 1) needs only the iid model and the sup in the denominator; it holds whether or not Q contains P*.
- Optional stopping is fully allowed: the guarantee is uniform over stopping rules (Corollary 1), and the sequential construction requires no data splitting.
- Growth (Theorem 2) needs Conditions 1–4 of Supp. C for the PR side and condition (9) for the null side; (9) with equality is argued via a Glivenko–Cantelli property of the null log-likelihood class and consistency of the null MLE for the KL projection (Supp. C.3, citing Patilea 2001, Kleijn and van der Vaart 2006, Doss and Wellner 2016 for log-concave densities).
- PR weights w_i = (i + 1)^{−0.67} throughout; the integration in the PR update is by quadrature on a grid over U when U is low-dimensional and by the authors' "PRticle filter" (Dixit and Martin 2023a) otherwise; high-dimensional U is left open.
- The denominator is the null MLE, not the RIPr. The authors note that Safe Testing would instead divide q̂^pr(X^n) by the RIPr density p0^rip(X^n), ask how to compute it in this nonparametric setting and whether the resulting ratio is even an e-process, and leave both questions open [dixitAnytimeValidAsymptotically2023, Sec. 3.1].

## Relation to other sources
- [wassermanUniversalInference2020](wassermanUniversalInference2020.md): the PRe-process is explicitly the no-splitting, running-MLE variant of universal inference (their Sec. 8) with a specific numerator; the multiplicative form (5) is cited as "a driving force behind the general formulation" there. Empirically, data splitting halves the growth slope (Sec. 5.1).
- [grunwaldSafeTesting2024](grunwaldSafeTesting2024.md): the comparison target for optimality. The PRe-process matches the GRO rate K(P*, P0) to first order when P* is the alternative; the paper declines to replace the MLE denominator with the RIPr. In the Safe Testing discussion Martin raised exactly this exact-vs-asymptotic point, and the authors' reply [grunwaldAuthorsReplyDiscussion2024](grunwaldAuthorsReplyDiscussion2024.md), Sec. 2, agrees that UI and GRO coincide in e-power up to sublinear terms but says that for d × d multivariate Gaussian problems with n not much larger than d the finite-n gap in both classical power and e-power "can be extreme" (citing Tse and Davison 2022, Spector, Candès and Lei 2023), attributing the loss to the UI denominator and not to predictive recursion, which they like as an alternative to Robbins' mixtures and plug-in. The two views are consistent: Theorem 2 is a first-order statement, and the o(n) gap here is already polynomial (n^{1/3}–n^{2/3}) for the numerator alone.
- [ramdasGametheoreticStatisticsSafe2023](ramdasGametheoreticStatisticsSafe2023.md): source of the "likelihood ratio is growth rate optimal" phrasing used to justify (10), of the e-process definition as a process dominated by a test martingale for each null, and of the method-of-mixtures / plug-in taxonomy into which PR fits (a non-Bayesian recursive plug-in whose numerator is nonetheless a mixture density). Its open question on the power of UI for log-concavity is partly answered empirically here.
- [ramdasAdmissibleAnytimevalidSequential2022](ramdasAdmissibleAnytimevalidSequential2022.md): cited (as Ramdas, Ruf, Larsson and Koolen 2022, Sec. 8.2) for the behaviour of e-processes under a true null, supporting the vanishing claim after Theorem 2.
- [haoEValuesExponentialFamilies2025](haoEValuesExponentialFamilies2025.md): quantifies, for exponential families, the (d/2) log n and O(1) losses of the UI and plug-in numerators relative to GRO, the parametric counterpart of this paper's polynomial oracle gap.
- [larssonNumeraireEvariableReverse2025](larssonNumeraireEvariableReverse2025.md): proves UI (MLE denominator) is dominated by the numeraire; this paper's reluctance to use the RIPr denominator is the nonparametric computational side of the same gap.
- [shinEdetectorsNonparametricFramework2023](shinEdetectorsNonparametricFramework2023.md) and [sahaNonpartitionedEdetectorsNonparametric2026](sahaNonpartitionedEdetectorsNonparametric2026.md): use UI e-processes for log-concavity as change-detector inputs; the PRe-process is a drop-in replacement with cheaper updates.

## Open questions / gaps
- Can the RIPr denominator be computed for nonparametric mixture alternatives, and is q̂^pr / p0^rip an e-process? Left open in Sec. 3.1; the Safe Testing reply's "extreme" finite-n loss of UI makes this the most consequential gap.
- Exact size of the o(n) oracle gap: proved n^{2/3}, conjectured n^{γ/2} ≈ n^{1/3} for interior P*, with the near-2/3 lower bound on γ possibly fundamental (Supp. E); no finite-sample bounds; PR theory cannot yet exploit smoothness of P*.
- Whether κ*(P0) < K(P*, P0) occurs only when the null MLE is inconsistent (Neyman–Scott, Supp. C.3) is a "hunch".
- High-dimensional U: the PRticle filter handles moderate dimension (d = 3 to 5 for diagonal Gaussian mixtures); beyond that new ideas are needed (Sec. 6).
- Regret-type nonasymptotic bounds for PR as a prequential forecasting system, calibration of PR beyond the iid case, and prequential consistency of the PR-marginal-likelihood estimator θ̂^pr (Supp. A).
- Theory and empirics for the kernel-free recursive-Bayes-predictive e-process E^rbp (Supp. G).
- Not in the bib: Gangrade, Rinaldo and Ramdas 2023 (sequential log-concavity test); Dunn, Gangrade, Wasserman and Ramdas 2024 (UI with random projections for log-concavity); Martin and Tokdar 2009, 2011; Dixit and Martin 2023a, 2023b; Newton 2002; Dawid 1984; Li and Barron 2000; Hahn, Martin and Walker 2018; Shafer, Shen, Vereshchagin and Vovk 2011; Martin 2023a (comment on Waudby-Smith and Ramdas).
