# Sequential change detection via backward confidence sequences

## Summary
The paper gives a reduction from sequential estimation to sequential change detection: if a confidence sequence (CS) can be built for a parameter or functional θ of the data distribution, then changes in θ can be detected with explicit false-alarm and delay guarantees [shekharSequentialChangeDetection2023, Sec. 1]. The setting is the harder, non-partitioned one in which pre- and post-change parameters θ0 ≠ θ1 both lie in one common index set Θ, possibly infinite-dimensional, with no separation assumed (Remark 1). A warm-up detector that stops when a single forward CS becomes self-contradictory controls the probability of a false alarm at α but has infinite average run length and a delay that grows like √T with the change time (Sec. 3). The main BCS-Detector pairs the forward CS with a new backward CS, rebuilt at every time n from the time-reversed observations X_n, …, X_1, and stops the first time the two smallest sets are disjoint (Sec. 4); Theorem 13 gives E_∞[τ] ≥ 1/(2α) − 3/2 and an expected delay, independent of T, of at most 3/(1−α) times the sample size at which the sum of the two CS widths drops below d(θ0, θ1). Five instantiations (Gaussian mean, bounded mean, CDFs in the Kolmogorov–Smirnov metric, kernel-MMD homogeneity of paired streams, harmful distribution shift for a deployed classifier) all inherit delays of order (log(1/α) + log log(1/Δ))/Δ², and the Gaussian case matches Lorden's lower bound up to logarithmic factors without knowing θ1 (Sec. 5). Appendix F reads the scheme as repeated sequential two-sample tests over all split points and shows that CuSum is itself a sequence of backward power-one likelihood-ratio tests.

## Main results
- **Definition 2, Remark 3, Definition 5**: level-(1−α) CS {C_t} with P(∀t : θ ∈ C_t) ≥ 1−α, taken nested without loss by running intersection; pointwise width w(t, θ, α) = sup_{θ' ∈ C_t} d(θ, θ') and uniform width w(t, Θ, α). Example 6: the Gaussian-mean CS X̄_t ± w_t/2 with w_t = 3.4 √((log log(2t) + 0.72 log(10.4/α))/t) from Howard et al. (2021).
- **Definition 7, Proposition 8 (FCS-Detector)**: stop at min{n : ∃t < n, C_t ∩ C_n = ∅}. (i) P_∞(τ < ∞) ≤ α. (ii) If w(T) < d(θ0, θ1), then with probability ≥ 1−α, τ − T ≤ min{t − T : w(t) + w(T) ≤ d(θ0, θ̃_t)} with θ̃_t = (T/t)θ0 + (1 − T/t)θ1. Remark 9 and Appendix B: for w(t) ≈ 1/√t the delay is linear in T when T ≈ 1/Δ² and of order √T/Δ as T → ∞; the ARL is infinite, so no expected-delay bound exists.
- **Definition 11 (backward CS)**: for each n, sets B^{(n)}_t, t ∈ [n], with B^{(n)}_t measurable in σ(X_t, …, X_n) and P(∀t ∈ [n] : θ ∈ B^{(n)}_t) ≥ 1−α. Appendix A: build it by applying any forward CS construction to Y_s = X_{n+1−s} and re-indexing; one forward CS for the whole run, a fresh backward CS at each n.
- **Definition 12 (BCS-Detector)**: τ = inf{n ≥ 1 : C_n ∩ B^{(n)}_1 = ∅}; for nested sequences this is equivalent to any C_r ∩ B^{(n)}_s = ∅.
- **Theorem 13**: (i) under no change, E_∞[τ] ≥ 1/(2α) − 3/2 (the proof, Appendix C, gives 1/(2α) − 3/2 + α via the union bound P_∞(τ ≤ N) ≤ (N+1)α over the N backward CSs plus the forward one). (ii) For T < ∞, α < 0.5 and the forward-coverage event E = {θ0 ∈ C_t : 1 ≤ t < T} with P_T(E) ≥ 1−α, E_T[(τ − T)^+ | E] ≤ 3 u_0/(1−α), where u_0 = min{t ≥ 1 : w(t, θ1, α) + w(T, θ0, α) < d(θ1, θ0)}. The bound does not depend on T (Remark 15).
- **Proof idea (Appendix C)**: backward CSs over the disjoint post-change blocks [T + (j−1)u_0, T + j u_0) are independent of each other and of E, so P_T(τ > T + i u_0 | E) ≤ α^i; summing the geometric tail gives u_0 (i_0 + α^{i_0}/(1−α)) with i_0 = ⌈log(1/(1−α))/log(1/α)⌉ = 1 for α < 0.5. The argument never uses θ0, θ1 or the direction of change.
- **Corollary 14**: with θ0 known, E_T[(τ − T)^+] ≤ (3/(1−α)) t_0 unconditionally, t_0 = min{t : w(t, θ1, α) < d(θ1, θ0)}.
- **Remark 16**: changepoint estimate T̂ = max argmax_{t ≤ τ} d(C_t, B^{(τ)}_t) and magnitude estimate Δ̂ = max_{θ ∈ C_{T̂}, θ' ∈ B^{(τ)}_{T̂}} d(θ, θ'); empirically accurate (Figures 1, 6–9), no guarantees.
- **Corollary 17, Remark 18 (Gaussian mean, Sec. 5.1)**: with d_KL = (θ1 − θ0)²/2 and T = Ω(log(1/d_KL)/d_KL), E_T[(τ − T)^+ | E] = O((log log(1/d_KL) + log(1/α))/d_KL). Lorden's (1971) lower bound for known θ0, θ1 is log(1/α)/d_KL (1 + o(1)), so the BCS-Detector is order-optimal modulo logarithmic factors without knowing θ1, unlike Pollak and Siegmund (1991) which needs a known lower bound on the change and T → ∞. Figure 1: Δ = 0.4, T = 800, one trial stops at τ = 1264; Figure 2: average delay ∝ 1/Δ² across all five instantiations.
- **Proposition 19, Proposition 30 (bounded mean, Sec. 5.2, App. D.2)**: observations in [0, 1], empirical-Bernstein CS of Waudby-Smith and Ramdas (2023) with the closed-form width w_t = (log(2/α) + Σ v_i ψ_E(λ_i))/Σ λ_i; with θ0 known, E_T[(τ − T)^+] = O((σ1² log(1/Δ) + log(1/α))/Δ²) where σ1² is the post-change variance. The variance adaptivity comes from a modified level-(1−2α) backward CS whose width is O(σ1 (√log(1/α) + √log t)/√t), proved by time-uniform concentration of the U-statistic variance estimate as a reverse martingale (Manole and Ramdas 2021, Cor. 8) and Orabona's Lemma 4.13. Remark 21: sub-Gaussian and heavy-tailed (Catoni) CSs plug in the same way.
- **Corollary 22 (CDFs, Sec. 5.3)**: Θ = all CDFs on R with the KS metric, CS of Howard and Ramdas (2022) with w_t = 1.7 √((log log(et) + 0.8 log(1612/α))/t); with F0 known, E_T[(τ − T)^+] = O((log log(1/Δ) + log(1/α))/Δ²), Δ = d_KS(F0, F1). Experiments on t_3 distributions with Δ ≈ 0.4.
- **Corollary 23, Remarks 24–26 (two paired streams, Sec. 5.4)**: Θ = product laws P × Q on U × U, d(θ0, θ1) = |ρ(P_U, P_V) − ρ(Q_U, Q_V)| for a probability metric ρ; instantiated with the kernel-MMD CS of Manole and Ramdas (2021) for a kernel bounded by 1. E[(τ − T)^+ | E] = O((log(1/α) + log log(1/Δ))/Δ²). When P_U = P_V is known pre-change this matches the kernel CuSum of Wei and Xie (2022). Any convex statistical distance (Wasserstein, f-divergences, IPMs) works via reverse-submartingale CSs. Cost O(τ³) overall (O(t²) per backward CS), reducible by linear or block MMD or by rebuilding the backward CS less often. Experiments in p = 5 dimensions, Δ ≈ 0.33.
- **Sec. 5.5 (harmful distribution shift)**: following Podkopaev and Ramdas (2021), θ = expected bounded loss of a deployed model; one-sided variant with an upper forward CS and lower backward CSs detects only risk increases θ1 > θ0; linear-classifier example with Δ ≈ 0.16.
- **Sec. 5.6**: further instantiations without analysis: exponential families (Chowdhury et al. 2022), covariance matrices (Howard et al. 2021, §4.3), RKHS regression (Chowdhury and Gopalan 2017), Huber-robust (Wang and Ramdas 2023) and locally private (Waudby-Smith, Wu and Ramdas 2022) CSs.
- **Proposition 29 (App. D.1)**: if t_0 = min{t : c √((log log t + log(1/α))/t) ≤ Δ/2}, then t_0 = O(c² (log log(c/Δ) + log(1/α))/Δ²); this single lemma yields Corollaries 17, 22, 23.
- **Appendix F, Definitions 33–34, Proposition 35**: the BCS-Detector is equivalent to running, at each t, a sequential test of "same distribution" for every split s < t. CuSum with threshold b_α equals CuSum-II, which at each n runs backward power-one likelihood-ratio tests L^n_t = Π_{s=n−t+1}^{n} f1(X_s)/f0(X_s) ≥ b_α and stops at the first n where some backward test rejects.

## Setting and assumptions
- Observations X_1, X_2, … i.i.d. from P_{θ0} for t ≤ T and from P_{θ1} for t > T, T ∈ N ∪ {∞}, θ0 ≠ θ1 in a common index set Θ with a metric d; null H0 = {T = ∞}. No densities, no separation of pre- and post-change classes, and neither θ0 nor θ1 nor the direction of change is needed for the ARL bound (Remark 1, App. C). Remark 4 and Definition 27: independent non-i.i.d. data with the CS covering the running average of parameters, when Θ is a vector space.
- Guarantees: ARL E_∞[τ] ≥ 1/(2α) − 3/2 for the BCS-Detector (the guideline α ≈ 10⁻³); PFA ≤ α for the FCS-Detector. The authors note the trade-off: PFA control forces infinite ARL and a T-dependent delay, ARL control tolerates infrequent false alarms (Sec. 1, Sec. 3).
- Delay bounds for the BCS-Detector are conditional on the forward-coverage event E of probability ≥ 1−α unless θ0 is known (Corollary 14, Remark 20); detectability requires enough pre-change data, w(T) < d(θ0, θ1), since T = 0 and T = ∞ are information-theoretically equivalent (Remark 10).
- Stopping is at the detector's stopping time τ by construction; the CSs themselves are the anytime-valid ingredients.

## Open questions / gaps
- Rebuilding a backward CS every round costs O(t²) per step and O(τ³) overall; whether sparser updates keep the same guarantees is open (Conclusion (i), Remark 26).
- No theoretical guarantees for the changepoint and magnitude estimators of Remark 16 (Conclusion (ii)).
- The ARL bound 1/(2α) − 3/2 comes from a union bound over n + 1 confidence sequences; its tightness is not discussed, and the delay bounds are conditional on forward coverage unless θ0 is known.
- Delay bounds carry a log log(1/Δ) factor and a constant 3/(1−α) over Lorden's rate; the paper claims optimality only modulo logarithmic factors (Remark 18).
