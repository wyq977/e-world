# Reverse information projections and optimal e-statistics

Notation warning: this paper writes P for the simple alternative and C (elements Q) for the convex null, the reverse of the convention used elsewhere in this wiki. The page keeps the paper's notation.

## Summary
Li's theorem and Theorem 1 of Safe Testing give the [reverse information projection](../concepts/reverse-information-projection.md) Q̂ of an alternative P on a convex null C, and the [GRO](../concepts/gro-criterion.md) e-statistic dP/dQ̂, only when D(P ‖ C) := inf_{Q ∈ C} D(P ‖ Q) is finite [lardyReverseInformationProjections2023, Thms 1–2]. The paper replaces the information divergence with Topsøe's description gain D(P ‖ Q ⇝ Q′) = ∫ ln(dQ′/dQ) dP − (Q′(Ω) − Q(Ω)), the gain from coding with Q′ instead of Q when data follow P, which is defined even when both D(P ‖ Q) and D(P ‖ Q′) are infinite; the maximum description gain D(P ‖ Q ⇝ C) = sup_{Q′ ∈ C} D(P ‖ Q ⇝ Q′) measures how far Q is from best in C [lardyReverseInformationProjections2023, eqs 1–2, Sec. I]. Theorem 3 shows that whenever some Q ∈ C has finite maximum description gain there is a unique limit Q̂, in a metric m_P that symmetrises the description gain, of every sequence with D(P ‖ Q_n ⇝ C) → 0, and that ∫ (dP/dQ̂) dQ ≤ 1 for all Q ∈ C; this Q̂ coincides with Li's RIPr whenever D(P ‖ C) < ∞ and is simply called the RIPr [lardyReverseInformationProjections2023, Thm 3, Prop. 2]. Theorem 5 shows that dP/dQ̂ is the strongest e-statistic: for every other e-statistic E, ∫ ln((dP/dQ̂)/E) dP ≥ 0, a pairwise criterion that reduces to GRO when the e-powers are finite and that still discriminates when they are all infinite [lardyReverseInformationProjections2023, Def. 2, Thm 5, Example 1]. The paper further shows that the RIPr can be a strict sub-probability measure already on a countable sample space, gives a domination condition on the null's constraints that rules this out, adapts the Li–Barron greedy algorithm to infinite KL with a 1/k rate in description gain, and proves tight rates (between δ^{1/2} and δ) at which description-gain approximations become approximate e-statistics [lardyReverseInformationProjections2023, Example 2, Thm 4, Prop. 5, Thm 6]. Section IV-C acknowledges the concurrent [numeraire](../concepts/numeraire.md) of Larsson, Ramdas and Ruf as the assumption-free form of the same object [lardyReverseInformationProjections2023, Sec. IV-C].

## Main results
- Theorem 1 (Li 1999, Def. 4.2 and Thm 4.3, restated): for probability measures with D(P ‖ C) < ∞ there is a unique, possibly sub-probability, Q̂ with ln q_n → ln q̂ in L_1(P) along every KL-minimising sequence, ∫ ln(dP/dQ̂) dP = D(P ‖ C), and ∫ (dP/dQ̂) dQ ≤ 1 for all Q ∈ C.
- Theorem 2 (Safe Testing, Thm 1, restated): under the same conditions plus p > 0 everywhere, dP/dQ̂ is GRO with growth rate D(P ‖ C), and any GRO e-statistic equals it P-a.s.
- Section III, eqs 3–4: the metric m_P(f, f′)² = ½ ∫ (ln(f̄/f) + ln(f̄/f′)) dP with f̄ = (f + f′)/2, the averaged Bregman divergence of γ(x) = x − 1 − ln x (an averaged Itakura–Saito divergence), equals ½ D(P ‖ Q ⇝ Q̄) + ½ D(P ‖ Q′ ⇝ Q̄) for densities in C. It is a metric on M(Ω, R_{>0}) modulo P-null sets by Chen, Chen and Rao 2008; convergence in m_P is equivalent to L_1(P) convergence of logarithms (Lemma 2); the space is complete (Proposition 1).
- Theorem 3 (first central result): if inf_{Q ∈ C} D(P ‖ Q ⇝ C) < ∞ there is a measure Q̂ such that for every sequence Q_n with D(P ‖ Q_n ⇝ C) → inf: (1) q_n → q̂ in m_P; (2) ∫ ln(dP′/dQ̂) dP = lim ∫ ln(dP′/dQ_n) dP for every P′ with finite |inf_Q D(P ‖ Q ⇝ P′)|; (3) ∫ (dP/dQ̂) dQ ≤ P(Ω) + Q(Ω) − liminf Q_n(Ω) for all Q ∈ C. Theorem 1 is the special case D(P ‖ C) < ∞. The density is unique only as an element of M(Ω, R_{>0}); the term "generalized RIPr" is avoided because Csiszár–Matúš 2003 use it for a non-attained RIPr.
- Proposition 2: existence of some P′ with finite D(P ‖ P′ ⇝ C), existence of some Q ∈ C with finite D(P ‖ Q ⇝ C), and existence of a sequence with D(P ‖ Q_n ⇝ C) → 0 are equivalent; hence the infimum of the maximum description gain, when finite, is zero. A Q ∈ C with D(P ‖ Q ⇝ C) = 0 is the RIPr.
- Proposition 3: for C = conv{Q_1, …, Q_n} and P ≪ Q_i for some i, the uniform mixture has finite maximum description gain, so the RIPr exists.
- Proposition 4: if C has finite minimax regret with normalised maximum likelihood (Shtarkov) distribution Q* ∈ C and P ≪ Q*, then D(P ‖ Q* ⇝ C) < ∞. One-dimensional exponential families with finite minimax regret are classified in Grünwald and Harremoës 2009.
- Example 1: P standard Cauchy, C = {N(0, 1)}: D(P ‖ C) = ∞ but D(P ‖ Q ⇝ Q) = 0, so N(0, 1) is the RIPr; with C = conv{N(−1, 1), N(1, 1)} the RIPr exists by Proposition 3 and is the uniform mixture by symmetry.
- Section III-A, eq. 5: for probability-measure P and C the RIPr is always a sub-probability measure (Fatou). Example 2: Ω = N, P = δ_1, C = {Q : Σ_i q(i)/i = 1/2}; then q(1) ≤ 1/2, D(P ‖ C) = ln 2, and Q_n = ((n−2)/(2n−2)) δ_1 + (n/(2n−2)) δ_n converges to the strict sub-probability measure ½ δ_1, which is therefore the RIPr even though D(P ‖ C) < ∞.
- Theorem 4: on Ω = N, if all Q ∈ C satisfy Σ f_0(i) q(i) ≤ λ_0 and Σ f_1(i) q(i) = λ_1 with f_1(i)/f_0(i) → 0, then any pointwise limit of a sequence in C still satisfies Σ f_1(i) q*(i) = λ_1; so a constraint dominating the constant function (f_1 → ∞) forces the RIPr to be a probability measure. Appendix B, Proposition 8: for C = {Q : Σ g(i) q(i) ≤ ν} with g → 0 the optimal e-statistic is g/ν and the RIPr q̂(i) = ν p(i)/g(i) has total mass ν Σ p(i)/g(i) < 1 for suitable ν, a template for strict sub-probability RIPrs that survives restriction to probability measures.
- Algorithm 1 / Proposition 5 (Section III-B): the Li–Barron greedy mixture algorithm (α_k = 2/(k+1), simplification due to Brinda 2018), with the step objective D(P ‖ (1−α_k) Q_{k−1} + α_k Q_θ′ ⇝ Q*) for a fixed reference Q* ∈ C of finite gain, achieves D(P ‖ Q_k ⇝ Q) ≤ b_Q^{(k)}(P)/k for every countable mixture Q ∈ C, where b is an integrated squared-likelihood-ratio quantity (eq. 8); uniform boundedness of b gives rate 1/k to the RIPr. For the two-Gaussian mixture null it is finite whenever P has a finite first moment. The step objective need not be convex in θ′; the Csiszár–Tusnády 1984 alternating algorithm is a faster alternative for finite Θ and finite KL, with unknown rate.
- Section III-C: the m_P machinery was developed to repair a gap in Li's proof of Theorem 1(1), which showed convergence for one minimising sequence (Lemma 4.3) but not for every sequence nor uniqueness of the limit.
- Definition 2 (Section IV): E is stronger than E′ if ∫ ln(E/E′) dP is well defined and ≥ 0 (possibly ∞); a strongest e-statistic is stronger than every e-statistic. Motivation: by the law of large numbers, Π E(ω_i)/Π E′(ω_i) = exp(n ∫ ln(E/E′) dP + o(n)) under P, so a stronger e-statistic eventually accumulates more evidence in repeated testing, also under data-dependent stopping. Under the standing assumption P ≪ Q* for some Q* ∈ C, P(E = ∞) = 0 for every e-statistic.
- Proposition 6: if some E′ has sup_E ∫ ln(E/E′) dP < ∞, a strongest e-statistic exists and is P-a.s. unique.
- Theorem 5 (second central result): for probability measures with inf_Q D(P ‖ Q ⇝ C) < ∞, dP/dQ̂ is the strongest e-statistic. When ∫ ln E dP is finite for both, "stronger" is the difference of e-powers, so this strictly generalises Theorem 2.
- Proposition 7: if dP/dQ* is an e-statistic for some Q* ∈ C, then D(P ‖ Q* ⇝ C) = 0, so Q* is the RIPr; the likelihood ratio with P on top is unique among e-statistics (proof as in Li, Lemma 4.1).
- Example 1 (continued): Cauchy vs Gaussian, every c · dP/dQ with c ∈ (0, 1] is an e-statistic with infinite growth rate, so GRO cannot rank them; Theorem 5 says dP/dQ (c = 1) is strongest.
- Section IV-A, Corollary 1, Appendix C: the e-statistics of C, conv(C), σ-conv(C) (countable mixtures) and the Choquet-convex hull (arbitrary mixtures, Polish spaces) coincide by Fubini–Tonelli, so a strongest e-statistic for any hull serves the original non-convex null; RIPrs on different hulls coincide when they exist, and an attained RIPr on a weaker hull is the RIPr on the stronger hulls. Theorem 7: if the RIPr on conv(C) exists then it exists on σ-conv(C) too. Example 4: P geometric on N_0, C the finitely supported distributions: no RIPr on conv(C) (every gain is −∞), while the RIPr on σ-conv(C) = all distributions on N_0 is P itself.
- Theorem 6 (Section IV-B): with δ = D(P ‖ Q ⇝ C) and ‖q′/q‖_{1+β} < ∞ for some β ∈ (0, ∞], and either β ≤ 1 or D(P ‖ Q′ ⇝ C) ≤ Kδ, ∫ (p/q) dQ′ = 1 + O(C_β δ^{β/(1+β)}) as δ → 0. Bounded second moments of likelihood ratios give ∫ (p/q_k) dQ′ = 1 + O(δ_k^{1/2}) uniformly, so Algorithm 1's output becomes an approximate e-statistic. The square root is tight: Bernoulli(1/2) vs Bernoulli(1/2 + ε) with null parameters in [1/4, 3/4] has δ = 2ε²(1+o(1)) but ∫ (q′/q) dP = 1 + 4ε(1+o(1)). A linear rate holds for bounded ratios in a Kδ-neighbourhood. Example 3 (geometric family): D(P ‖ Q_θ_i) → 0 while sup_θ′ ∫ (q_θ′/q_θ_i) dP = ∞ for every i, so some moment bound is necessary.
- Section IV-C: Zhang, Ramdas and Wang 2023 prove likelihood-ratio e-statistics exist for convex-polytope nulls; this follows from Proposition 3. For a convex-polytope alternative A with inf_{P ∈ A} D(P ‖ C) = ∞, the likelihood ratio of the uniform vertex mixture P* against its RIPr has infinite e-power at every vertex, ∫ ln(dP*/dQ̂*) dP ≥ D(P ‖ C) − ln n, hence "nontrivial e-power" in their sense.
- Section V (future work): Poissonisation interpretation of the RIPr for non-probability measures (D(P ‖ Q ⇝ Q′) = D(Po(P) ‖ Po(Q) ⇝ Po(Q′)) on finite Ω); and reverse Rényi projections Q̂_α of order α ∈ (0, 1) (Kumar and Sason 2016), for which (dP/dQ̂_α)^α is an e-statistic when the projection exists, with the conjecture that Q̂_α → RIPr as α → 1.

## Setting and assumptions
- Measurable space (Ω, F); P a finite measure (the alternative) and C a convex set of finite measures (the null), all with densities w.r.t. a common σ-finite μ; at least one Q* ∈ C with P ≪ Q*, needed so that D(P ‖ Q ⇝ C) ∈ [0, ∞] is well defined [lardyReverseInformationProjections2023, Sec. II-A]. Sections III-A and IV restrict to probability measures.
- Convexity of C is assumed throughout (finite mixtures); σ- and Choquet-convexity are discussed in Appendix C, where all measures are taken to be sub-probability so that countable mixtures stay finite [lardyReverseInformationProjections2023, App. C].
- Single-outcome, fixed-sample statements; the sequential interpretation is only through products of i.i.d. e-statistics and the law of large numbers [lardyReverseInformationProjections2023, Sec. IV]. No optional stopping theory is developed; [optional continuation](../concepts/optional-continuation.md) is the stated motivation.
- Simple alternative only; composite alternatives appear only in the Section IV-C remark on convex-polytope alternatives.
- Existence of the RIPr is not unconditional: the standing hypothesis inf_Q D(P ‖ Q ⇝ C) < ∞ can fail (Example 4 on conv(C)); the paper does not claim a fully assumption-free theory and defers that to Larsson et al.

## Open questions / gaps
- The condition inf_Q D(P ‖ Q ⇝ C) < ∞ is sufficient but can fail on conv(C) while holding on σ-conv(C) (Example 4); whether an RIPr can exist on exactly one or two of the three hulls is left open [lardyReverseInformationProjections2023, Sec. IV-A]. Larsson et al. remove the condition entirely but only for e-variables, not for the metric convergence statement.
- Algorithm 1's step is non-convex in θ′ and the description gain may not be computable; no practical fast algorithm is given, matching the open problem in the RIPr concept page.
- Whether polytope-alternative e-statistics with infinite e-power are optimal in any sense, and whether the polytope restriction can be dropped [lardyReverseInformationProjections2023, Sec. IV-C].
- Poissonisation interpretation for non-probability measures beyond finite Ω; convergence of reverse Rényi projections to the RIPr as α → 1 [lardyReverseInformationProjections2023, Sec. V]. The latter is partly addressed by Larsson et al. Theorem 6.1, which proves existence of reverse Rényi projections of every order in (0, 1) but not the α → 1 limit.
- Not in the bib: Li 1999; Li and Barron 1999; Zhang, Ramdas and Wang 2023; Csiszár and Matúš 2003; Kumar and Sason 2016; Topsøe 2007.
