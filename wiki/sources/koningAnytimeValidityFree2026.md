# Anytime validity is free: inducing sequential tests

Econometric Institute, Erasmus University Rotterdam; the two authors contributed equally. Companion papers by the first author, "Continuous testing: unifying tests and e-values" (Koning 2025, arXiv 2409.05654) and "Post-hoc α hypothesis testing and the post-hoc p-value" (Koning 2024, arXiv 2312.08040), supply the test/e-value bridge and the data-dependent-α control used here. R code for the induced z- and t-tests is at github.com/nickwkoning/free_anytime_validity.

## Summary
Fix a test φ : X → [0, 1] at level α (E_P[φ] ≤ α) measured at a planned time N, and define its induced sequential test by the Doob martingale φ_n := E_P[φ | F_n] [koningAnytimeValidityFree2026, eq. 5]. Theorem 1 shows that (φ_n) is anytime valid (E_P[φ_τ] ≤ α for every stopping time τ) exactly when φ is valid, and that φ_τ = φ whenever φ is F_τ-measurable, so nothing is lost at time N; Proposition 2 shows conversely that every admissible anytime-valid sequential test is induced in this way from a single terminal test, so a sequential test is "summarised" by φ_∞ = lim sup φ_n. This is a backward construction (start from the target test, condition down) in contrast with the forward martingale-increment construction standard in the e-value literature (Remark 2). The second contribution is that a [0, 1]-valued outcome φ_1 is a conditional significance level: any φ_2 with E_P[φ_2 | φ_1] ≤ φ_1 is unconditionally valid at level α (Theorem 4), and a running anytime-valid test may be aborted at any stopping time σ and continued by a fresh sequential test that is conditionally anytime valid at level φ_σ (Theorem 5); on the e-value scale ε = φ/α this is exactly multiplying sequentially valid e-values (Remark 13). The paper derives closed forms for the induced one-sided z-test (eq. 6) and t-test (Sec. 4.2, via Beta distributions), proves both anytime valid for the full one-sided composite nulls μ ≤ 0 and {μ ≤ 0, σ² > 0} (Sec. 3.1, Prop. 5), characterises the log-utility-optimal e-process (the uncapped SPRT, LR_n) as the unique utility whose optimal e-value is invariant under induction (Theorem 7, Prop. 6), and shows that the SPRT is the limit of induced Neyman–Pearson tests with α_N = exp{−N·D(Q‖P)} as N → ∞ (Theorem 8). The authors read all this as dispelling the "myth" that anytime validity and optional continuation are properties of the e-value paradigm unavailable to traditional tests [koningAnytimeValidityFree2026, Sec. 1.3].

## Main results
- **Motivating gap (Sec. 1)**: N(μ, 1), test μ = 0 vs μ = 0.3, N = 100: the z-test has power 91%; the oracle SPRT αLR_n ∧ 1 rejects at some n ≤ N with probability 79% (84% with terminal randomisation); with the alternative learned by running MLE, 47%.
- **Definition (eq. 5)**: for simple null P and F-measurable φ, the induced sequential test is φ_n := E_P[φ | F_n], with φ_0 = E_P[φ] the size of φ (Remark 1); φ_∞ := lim sup_n φ_n.
- **Theorem 1 (simple hypotheses)**: (1) φ valid ⇒ (φ_n) anytime valid; (2) φ not valid ⇒ φ_τ not valid for any stopping time τ (a strong converse); (3) φ F_τ-measurable ⇒ φ_τ = φ. Stopping times τ in (3) must be fixed at induction time (Remark 3).
- **Proposition 1**: (φ_n) anytime valid ⇒ φ_∞ valid.
- **Proposition 2 (completeness)**: every admissible anytime-valid sequential test (no other anytime-valid (φ'_n) with φ'_n ≥ φ_n a.s. for all n and strict somewhere, the admissibility of Ramdas, Ruf, Larsson and Koolen 2022) equals E_P[φ | F_n] for some F-measurable test φ. Consequence: all properties of an admissible sequential test are those of one terminal test.
- **Remark 4 (computation)**: φ_n is the L²-projection of φ onto F_n-measurable functions, or can be approximated by sequential Monte Carlo / particle filtering when no closed form exists.
- **Proposition 3 (composite representation)**: φ^H is valid for H iff φ^H = ess inf_{P∈H} φ^P for some family (φ^P) with each φ^P valid for P (the batch analogue of the sequential infimum representation in Ramdas et al. 2022).
- **Theorem 2 (composite hypotheses)**: with φ^H_n := ess inf_P E_P[φ^P | F_n]: (1) every φ^P valid ⇒ (φ^H_n) anytime valid; (2) if every φ^P is F_∞-measurable and ess inf φ^P is not valid, (φ^H_n) is not anytime valid; (3) every φ^P F_τ-measurable ⇒ φ^H_τ = ess inf φ^P. Only φ^H_∞ ≥ lim sup φ^H_n holds in general (footnote 3). Remark 6: no canonical choice of (φ^P) is known; naive choices give ess inf φ^P ≠ the optimal test for H, or trivial processes 0, …, 0, φ*. Remark 7: uncountable H needs the essential infimum under local absolute continuity w.r.t. a reference measure.
- **Remark 5**: all results except Theorem 1(2) and Prop. 2 (which need the uniform integrability that boundedness in [0, 1] supplies) extend to e-values via the rescaling ε = φ/α.
- **Theorem 3 (sufficient MLR, generalising Grünwald and Koolen 2025)**: if for every n the model (P_δ)_{δ∈Δ} restricted to F_n has the monotone likelihood ratio property in a real sufficient statistic T_n and φ_n is non-decreasing in T_n, then a nonnegative P_{δ0}-martingale (φ_n) starting at α is anytime valid for all δ ≤ δ_0. The generalisation is from "φ_n is a likelihood ratio" to "φ_n is non-decreasing in T_n".
- **Proposition 4**: if F = σ(T), F_n = σ(T_n), φ non-decreasing in T and T stochastically non-decreasing in T_n under P_{δ0}, then φ_n = E_{δ0}[φ | F_n] is non-decreasing in T_n. The first condition holds for any utility-optimal test under MLR (via Koning 2025); MLR in a sufficient T does not by itself imply the second (counterexample, supplementary Appendix A).
- **Sequential z-test (Sec. 3, eq. 6)**: for φ_N = 1{N^{−1/2} Σ_{i≤N} X_i/σ > z_{1−α}}, φ'_n = Φ((N^{−1/2} Σ_{i≤n} x_i/σ − z_{1−α}) / √r_n) with r_n = (N − n)/N the fraction of observations remaining; at n = N the ratio y/0 is read as ±∞, giving the z-test decision. Sec. 3.1: inducing from every μ ≤ 0 and taking the infimum returns the μ = 0 process, so the same test is anytime valid for the composite one-sided null μ ≤ 0 (via Theorem 2).
- **Sequential t-test (Sec. 4)**: filtration F_n = σ(T_1, …, T_n) of t-statistics; φ'_n = E_{N(0,1)}[1{T_N > c_{α,N}} | F_n]; anytime valid for {μ = 0, σ² > 0} by Theorem 3 and scale invariance, and by Proposition 5 for the full H = {N(μ, σ²) : μ ≤ 0, σ² > 0}. Lemma 1: under N(0, σ²), T_N is stochastically increasing in T_n for every N > 1, n ≤ N. Sec. 4.2 closed form: φ'_n = ∫_0^1 F_B((N^{−1/2} Σ_{i≤n} x_i/‖x^n‖_2 · √w − β_{1−α}) / (√r_n √(1 − w))) f(w) dw, with F_B the CDF of a Beta((N−n−1)/2, (N−n−1)/2) on [−1, 1], β_{1−α} the α upper quantile of Beta((N−1)/2, (N−1)/2) on [−1, 1], and f the Beta(n/2, (N−n)/2) density; the √w term shrinks the statistic for small n. Remark 8: Prop. 5 covers any test non-decreasing in T_N, including the log-utility-optimal t-test of Pérez-Ortiz et al. 2024. Remark 9: validity extends to location shifts of spherically invariant distributions.
- **Theorem 4 (two tests)**: if φ_1 is valid at α and E_P[φ_2 | φ_1] ≤ φ_1 for all P ∈ H, then φ_2 is valid at α (one-line proof by the tower rule). Remark 12: binary tests are poor first tests (φ_1 = 0 kills continuation, φ_1 = 1 already rejected), which the authors suspect is why the idea was not picked up earlier.
- **Theorem 5 (anytime validity and optional continuation)**: for an anytime-valid (φ_n) and any stopping time σ, a test φ* with E_P[φ* | F_σ] ≤ φ_σ is valid, and a sequential test (φ*_n)_{n≥σ} that is conditionally anytime valid at level φ_σ spliced after σ gives an anytime-valid (φ†_n) = φ_1, …, φ_σ, φ*_{σ+1}, …. Remark 10: an induced test is already doing optional continuation at every step (E_P[φ'_n | F_{n−1}] = φ'_{n−1}), so continuation cannot raise power at N beyond a most powerful φ_N, only at other stopping times. Remark 11: redesign at a stopping time branches the filtration, and the branching process defines a bona fide filtration (G_n), so no new theory is needed.
- **Remark 13**: with ε_1 = φ_1/α and ε_2 = φ_2/φ_1, the procedure is multiplying sequentially valid e-values, E_P[ε_1 ε_2] ≤ 1 with ε_1 ε_2 ∈ [0, 1/α].
- **Sec. 5.1 (switching levels)**: for a data-independent α', take E_P[φ_2 | F_1] ≤ φ_1 α'/α and get E_P[φ_2] ≤ α'. For a data-dependent α' the unconditional requirement is ill-posed; under the data-dependent type-I control E_P[φ_2/α'] ≤ 1 of Koning 2024 and Grünwald 2024, the same conditional level φ_1 α'/α yields validity at α', so one may continue after a rejection at α to seek a rejection at α' < α.
- **Theorem 6 (pointwise optional continuation)**: if each φ^P_1 is valid for P at α and each φ^P_2 is conditionally valid for P at level φ^P_1 given F_1, then φ^H_2 = ess inf φ^P_2 is valid for H at α. This dominates continuing from the single ess inf φ^P_1, so one should report the whole family (φ^P)_{P∈H} (cf. fuzzy confidence sets, Koning and van Meer 2025; e-posterior, Grünwald 2023).
- **Sec. 6.1 (e-values as rescaled tests)**: a level-α test on [0, 1/α] has sup_P E_P[ε] ≤ 1 regardless of α; α = 0 recovers e-values on [0, ∞]. Neyman–Pearson power is expected utility with U(x) = x ∧ 1/α; concave U gives continuum-valued e-values; for mutually absolutely continuous P, Q and concave non-decreasing U the U-optimal e-value satisfies λ dP/dQ ∈ ∂U(ε*) (eq. 8, Koning 2025), hence is non-decreasing in dQ/dP.
- **Theorem 7 (conditioning invariance)**: P ≫ Q; if ε is log-utility-optimal for P against Q then ε_n = E_P[ε | F_n] is log-utility-optimal for P|F_n against Q|F_n. The induced process is (LR_n), the uncapped SPRT on the e-scale (α = 0).
- **Proposition 6 (uniqueness of log)**: for U concave, strictly increasing, differentiable with continuous strictly decreasing U', U'(0) = ∞, U'(∞) = 0, if U-optimality is preserved under induction for every pair P ≫ Q and every measure space, then U = log up to affine transformation (Jensen must hold with equality for g(x) = (U')^{−1}(c/x), forcing U(x) = a log(x − b) + c and U'(0) = ∞ forcing b = 0). The authors call this the first motivation of log-utility that does not rely on independence over time.
- **Theorem 8 (SPRT induced from Neyman–Pearson)**: P, Q mutually absolutely continuous, log dQ/dP atomless, D_{1+ε}(Q‖P) < ∞ for some ε > 0, log LR_1 non-lattice under P; with α_N = exp{−N·D(Q‖P)} and φ'_{n,α_N} the conditional expectation of the level-α_N NP test on N i.i.d. observations, lim_{N→∞} φ'_{n,α_N}/α_N = LR_n P-a.s. for every n. Remark 14: strictly stronger than Breiman 1961, who matched only the power at N uniformly in α; here the whole processes coincide. Figure 2: N(0.5, 1), N = 100, α = exp{−12.5} ≈ 3.7 × 10^{−6}, near overlap for n ≪ N.
- **Discussion (Sec. 7)**: the authors do not advocate inducing from Neyman–Pearson tests in practice: such tests stop at a finite N and hit 0 with positive probability, discarding continuation; the value is the theoretical bridge and the option to intervene before N. Research agenda: design good terminal tests (not of NP form) and induce; prefer [0, 1]-valued over {0, 1}-valued tests; the authors personally prefer the [0, 1/α] e-scale "for reasons listed in Koning (2025)" but stress the [0, 1] scale works.

## Setting and assumptions
- Filtered space (X, F, (F_n)_{n≥0}), F_0 trivial, F_∞ = σ(∪ F_n) ⊆ F; a test is any F-measurable map to [0, 1]; validity is sup_{P∈H} E_P[φ] ≤ α; anytime validity is validity of φ_τ for every possibly infinite stopping time, with φ_∞ := lim sup φ_n (eqs 3–4). The level α > 0 is fixed; the e-value scale is the α = 0 limit (Sec. 6.1).
- Simple-null results (Theorem 1, Props 1–2) are stated P-a.s.; composite results require a family (φ^P) and, for uncountable H, local absolute continuity w.r.t. a reference measure to define the essential infimum (Remark 7).
- Theorem 3 / Prop. 4 need MLR in a real sufficient statistic at every n and monotonicity in T_n; the z- and t-test sections assume i.i.d. Gaussian data (t-test results also hold under spherical invariance, Remark 9). The t-test filtration is generated by t-statistics, not the raw data, and the stopping times must be adapted to it.
- Theorem 8 is an i.i.d. large-deviation limit (Rényi moment condition, non-lattice log likelihood ratio, atomless log LR); it describes the SPRT as a limit object, not a finite-N identity.
- Optional stopping and continuation are both allowed by construction: Theorem 1 gives stopping at arbitrary τ, Theorem 5 gives continuation and redesign at arbitrary σ. No independence over time is assumed in Theorems 1, 2, 4, 5, 7 or Prop. 6.
- All omitted proofs (Theorem 1, Props 2, 5, Lemma 1, Theorems 7, 8, Prop. 6, the Beta derivation B.8) are in online supplementary Appendix B, which is not in the text layer.

## Disagreements
- **Authors' claim**: anytime validity and optional continuation "come naturally to tests", e-values are "tests in disguise, masked by a cosmetic rescaling" to [0, 1/α], and presenting these properties as advantages of a separate e-value paradigm is a "myth" [koningAnytimeValidityFree2026, Secs 1.3, 6.1]. The formal content is that every bounded test martingale started at α is an anytime-valid test (Theorem 1), every admissible one arises this way (Prop. 2), and continuation is the tower rule (Theorem 4).
- **Wiki's existing view**: the concept pages define anytime validity through [e-processes](../concepts/e-process.md) and [test martingales](../concepts/test-martingale.md) with [Ville's inequality](../concepts/villes-inequality.md), and [optional continuation](../concepts/optional-continuation.md) as multiplication of e-values [grunwaldSafeTesting2024, Cor. 1; ramdasHypothesisTestingEvalues2025, Prop. 7.9]; the survey calls tests and anytime p-values "secondary and derivative" of e-processes [ramdasGametheoreticStatisticsSafe2023, Sec. 2.4], and the reply to Safe Testing insists continuation across studies is the main point of e-values [grunwaldAuthorsReplyDiscussion2024, Sec. 2].
- **Where they agree**: the two are formally equivalent under the substitution ε = φ/α (Remark 13; Sec. 6.1), and the paper itself prefers the e-scale (Sec. 7). The disagreement is about framing, priority and the practical role of the [0, 1] interior, not about any theorem. Where they genuinely differ: (i) the backward Doob construction versus the forward increment construction as the primary design tool (Remark 2); (ii) whether bounded tests (U = x ∧ 1/α) or unbounded log-optimal e-values are the right terminal objects, which the paper leaves to future work (Sec. 7) while the e-value literature has settled on log; (iii) the paper's historical claim that the Lan–Simon–Halperin / Müller–Schäfer conditional-power stream anticipated these ideas and "has gone entirely unnoticed" in the anytime-valid renaissance (Sec. 1.4), which no ingested source discusses.

## Open questions / gaps
- How to choose the family (φ^P)_{P∈H} for a composite null so that ess inf φ^P equals the optimal test for H and the induced process is admissible is open (Remark 6); the infimum construction applied to per-δ t-tests gives a valid but inadmissible sequential t-test (Sec. 2.4).
- The essential-infimum construction for uncountable H is acknowledged as "somewhat unsatisfying"; the authors are unsure whether a clean solution exists within standard analysis (Remark 7).
- Induced tests from Neyman–Pearson terminal tests stop at N and may hit 0; the design of "good" terminal tests that avoid this, and the general programme "design the terminal test, then induce", is left open (Sec. 7).
- Whether pointwise continuation (Theorem 6) should replace reporting a single composite test outcome connects to fuzzy confidence sets and e-posteriors, both outside the bib.
- Theorem 8 is asymptotic and i.i.d.; a finite-N or non-i.i.d. version is not given.
