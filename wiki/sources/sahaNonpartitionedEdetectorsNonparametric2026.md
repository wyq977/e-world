# Non-partitioned e-detectors for nonparametric sequential change detection

arXiv preprint, July 2026. Code at github.com/Aytijhya/Nonseparated-e-detector [sahaNonpartitionedEdetectorsNonparametric2026, footnote 1].

## Summary
The paper treats sequential change detection when the pre-change law P and post-change law Q are both unknown members of one class 𝒫 on a Polish space, with no pre-specified partition 𝒫 = 𝒫_0 ⊔ 𝒫_1; the no-change null is "X_1, X_2, … i.i.d. R for some R ∈ 𝒫", and the alternative is X_1..X_T ~ P then X_{T+1}, … ~ Q with P ≠ Q [sahaNonpartitionedEdetectorsNonparametric2026, Sec. 1]. The only primitive is an s-delay [e-process](../concepts/e-process.md) M^R_{s:t} for each point null R and each start s (Definition 2.1). The detector sums these over starts, weighted by deterministic w_s, and takes an infimum over R: D^w_t = inf_{R ∈ 𝒫} Σ_{s ≤ t} w_s M^R_{s:t}, stopping when D^w_t ≥ A (eq. 1, 3, 46). Unit weights make D an [e-detector](../concepts/e-detector.md) with average run length ≥ A and local bound P(τ ≤ m) ≤ m/A (Theorem 2.2); summable weights π_s make D an e-process so that Ville gives a global probability of false alarm ≤ α (Theorem 2.3). Four worked classes (σ²-sub-Gaussian means, all laws on [0,1], Gaussians with unknown variance, two-state Markov chains) get explicit detectors and first-order delay bounds of the form (1+o(1)) (log A)/I for late changes, where I is the relevant KL or betting information; the PFA detector pays an extra −log π_{T+1} = log T + 2 log log(eT) + O(1) in the numerator (Theorems 3.2, 3.3, 4.2, 5.2, 5.3, A.3). A general theory shows that if 𝒫 has a "countable local REGROW witness basis" (Definition 6.8; implied by weak compactness, Proposition 6.9, and satisfied by the non-compact Gaussian location family, Proposition 6.10) there exist point-null e-processes whose detector attains the instance-specific rate (1+ε) (log A − log w_{T+1})/D_KL(Q‖P) with probability tending to one (Theorems 6.11, 6.13, Corollaries 6.14, 6.15). Matching lower bounds by change of measure show the rate L_α/D_KL(Q‖P) is pointwise unimprovable for PFA detectors (Theorem 7.1), that a horizon-uniform start-time price of order log T_max is unavoidable (Theorem 7.2), and that early changes T = o(log(1/α)) cannot be detected at all under PFA control (Theorem 7.3), with ARL analogues in Appendix B.4.

## Main results
- **Definition 2.1 (s-delay e-process)**: M^R_{s:j} = 1 for j < s, nonnegative adapted, E^∞_R[M^R_{s:τ} | F_{s−1}] ≤ 1 for every stopping time τ; existence for singleton nulls is supplied by the REGROW construction of Ram and Ramdas (2026b) [sahaNonpartitionedEdetectorsNonparametric2026, Sec. 2].
- **Theorem 2.2 (ARL control)**: D^ARL_t = inf_R Σ_{s=1}^t M^R_{s:t} is an e-detector; for every R ∈ 𝒫, E^∞_R[τ^ARL_A] ≥ A and P^∞_R(τ^ARL_A ≤ m) ≤ m/A for all m (eq. 2). Proof: for fixed R_0 the oracle Shiryaev–Roberts sum S^{R_0}_t dominates D_t and E[S_τ] ≤ Σ_s P(τ ≥ s) = E[τ] (App. B.1).
- **Theorem 2.3 (global PFA control)**: with π_s > 0, Σ π_s ≤ 1, D^PFA_t = inf_R Σ_s π_s M^R_{s:t} is an e-process, so P^∞_R(τ^PFA_α < ∞) ≤ α at threshold 1/α. Canonical weights π_s = c_π / (s (log es)²), −log π_s = log s + 2 log log(es) + O(1) (eq. 4–5).
- **Section 1.1**: under PFA control the CADD E[τ − T | τ > T] is infinite for any detector (P(τ = ∞) > 0 since Q is itself a no-change law), so PFA delay results are high-probability statements; under ARL control CADD is finite and bounded.
- **Proposition 3.1 / eq. 6 (sub-Gaussian)**: for the class of σ²-sub-Gaussian laws with mean θ, the Gaussian-mixture process M^θ_{s:t} = (1 + ρ²σ²n)^{−1/2} exp{ρ²n²(X̄_{s:t} − θ)² / (2(1 + ρ²σ²n))}, n = t − s + 1, is a test supermartingale; the detector is a one-dimensional infimum over θ (eq. 7, 11).
- **Theorem 3.2**: with A = 1/α, L = log A, T_α/L → ∞ and log T_α = o(L), τ^ARL_A − T_α ≤ (1 + o_P(1)) L/I and CADD ≤ (1 + o(1)) L/I, where I = inf_{P_0 ∈ 𝒫_μ, P_1 ∈ 𝒫_ν} D_KL(P_1‖P_0) = (μ − ν)²/(2σ²) (eq. 8). Deterministic bound τ_A ≤ ⌈(1 + ρ²σ²)A²⌉ on every path (App. C.1, Step A).
- **Theorem 3.3, Corollary 3.4**: the PFA detector satisfies τ^PFA_α − T_α ≤ (1 + o_P(1)) (L + h_π(T_α))/I with h_π(T) = O(log T) (eq. 12–16); the first-order term is unchanged when I T_α/L → ∞ and log T_α = o(L).
- **Section 4 / Proposition 4.1 (bounded means)**: for 𝒫 = all laws on [0,1], Cover's two-asset universal portfolio with arcsine (Jeffreys) mixing over constant bets λ_θ(p) = (p − θ)/(θ(1−θ)) gives an s-delay test martingale U^θ_{s:t} under any adapted process with E[X_t | F_{t−1}] = θ (eq. 17–18); its growth is at least the betting information I_bet(Q, θ) = sup_λ E_Q log{1 + λ(X − θ)}, which equals inf_{R: E_R X = θ} D_KL(Q‖R) (eq. 19–20, Lemma C.4) and is bounded below by kl(b, θ) for mean b, with equality in the worst case (Lemma C.5).
- **Theorem 4.2**: τ^{UP,ARL}_A − T_A ≤ (1 + o_P(1)) log A / I_bet with the same CADD bound; PFA version with numerator log(1/α) − log π_{T+1}. Exact evaluation of the arcsine mixture through horizon H by Gauss–Chebyshev quadrature with K ≥ (H+1)/2 nodes.
- **Proposition 5.1 / eq. 22–23 (Gaussian, unknown variance)**: the universal-inference t e-process R^θ_{s:t} = {n^{−1}Σ(X_i − θ)²}^{n/2} e^{n/2} Π_i φ_{μ̂,σ̂²}(X_i)-type predictive numerator (power-preserving translation of Wang and Ramdas 2024) is an s-delay e-process under every N(θ, σ²)^∞, with growth J_{m,v}(θ) = ½ log(1 + (m − θ)²/v) = inf_r D_KL(N(m,v) ‖ N(θ,r)) (eq. 24–25), the largest possible for the composite mean null.
- **Theorem 5.2**: the studentized detector (eq. 26, convex in θ, eq. 27) has delay (1 + o_P(1)) B_α / I_t(P,Q) with I_t = ½ log(1 + (b − a)²/v) and B_α = L_α − log w_{T+1} (eq. 28–32).
- **Theorem 5.3**: the full-Gaussian detector with predictive-density ratio L^{θ,r}_{s:t} (eq. 33, a test martingale under N(θ,r)^∞) and a two-dimensional infimum over (θ, r) (eq. 35) attains (1 + ε) B_α / D_KL(Q‖P), I_G = ½[log(u/v) + (v + (b − a)²)/u − 1] (eq. 36–37); for common variance I_t ≤ I_G with strict inequality (eq. 38). Convex after natural-parameter reparametrisation; O(t) per Newton step.
- **Definition 6.1, Lemma 6.2, Corollary 6.4 (adjusters)**: an adjuster a with ∫_1^∞ a(x)/x² dx ≤ 1 applied to the running maximum of an e-process yields an e-process (Choe and Ramdas 2026); growth-preserving if log a(e^y) = y − o(y), e.g. a(x) = 2x/(2 + log x)² (eq. 39). Adjusted s-delay e-processes are nondecreasing in t and retain pre-change evidence: M̄^R_{1:T+d} ≥ a(M^R_{1:T}) (eq. 40).
- **Lemma 6.5**: for I* = D_KL(Q‖P) ∈ (0, ∞), G_η = {R : D_KL(Q‖R) > I* − η} is a weakly open neighbourhood of P (Donsker–Varadhan lower semicontinuity) and inf_{R ∉ U} D_KL(P‖R) > 0 for any weakly open U ∋ P (eq. 41–42).
- **Definitions 6.6, 6.8; Lemma 6.7; Propositions 6.9–6.10**: simultaneous REGROW regularity (one nondecreasing e-process valid on K with lim inf n^{−1} log E_n ≥ inf_{R ∈ K} D_KL(S‖R) for every S in the alternative set); weakly compact classes are regular (via Ram and Ramdas 2026b, Theorem 2); a countable local REGROW witness basis is a countable base of weakly open sets with compact closures whose exteriors are regular over them; weak compactness suffices and {N(θ,1)} has one without being compact.
- **Theorem 6.11**: a witness basis yields nondecreasing s-delay e-processes such that, for any P, Q and η_in, there is a basis set B_{j*} ∋ P with inf_{R ∉ B_{j*}} log M^R_{1:n} ≥ n(c − η_out) under P^∞ and inf_{R ∈ B_{j*}} log M^R_{1:n} ≥ n(I* − η_in) under Q^∞, both with probability → 1 (eq. 43–44). Remark 6.12: what is really needed is local witnesses for a compact neighbourhood of P and its exterior, not compactness of 𝒫.
- **Theorem 6.13 (generic late-change bound)**: with B_α = L_α − log w_{T_α+1} and d_α = (1 + ε) B_α / I*, if T_α(c − η_out) + log w_1 ≥ L_α and d_α(I* − η_in) + log w_{T+1} ≥ L_α eventually (eq. 47–48), then P^{T_α}_{P,Q}(τ^w_α ≤ T_α + d_α) → 1. Remark 6.16: the post-change start alone cannot reject R = Q; the prefix term is needed and the adjuster keeps it alive.
- **Corollaries 6.14–6.15**: ARL detector, T_A/L → ∞: τ − T_A ≤ (1 + ε) L/I* + 1 w.p. → 1, also conditionally on no false alarm when T_A/A → 0; PFA detector: numerator log(1/α) − log π_{T+1} = log(1/α) + log T_A + 2 log log(eT_A) + O(1), and P(τ^PFA_α > T_A) ≥ 1 − α.
- **Theorem 7.1 (pointwise PFA lower bound)**: for any PFA-α stopping time and d_α ≤ (1 − ε) L_α / I*, P^{T_α}_{P,Q}(T_α < τ ≤ T_α + d_α) → 0.
- **Theorem 7.2 (horizon-uniform PFA lower bound)**: if the detector catches a change within d_α at each of N_α disjoint windows with probability ≥ 1 − β − ρ_α, then d_α ≥ (L_α + log N_α + log(1 − β) + o(1))/(I* + η) (eq. 50); the start-time price is log(T_max/d_α), i.e. log T_max to first order, matching the −log π_{T+1} term of the upper bound.
- **Theorem 7.3 (early-change impossibility)**: for any PFA-α detector and P ≪ Q, P^T_{P,Q}(τ < ∞) ≤ min{1, (T D_KL(P‖Q) + log 2)/log(1/α)}, so T_α = o(log(1/α)) makes detection probability vanish (data-processing inequality on the indicator of {τ < ∞}).
- **Theorems B.1, B.3; Corollary B.2**: ARL analogues under the local guarantee P^∞_R(τ_A ≤ m) ≤ m/A: pointwise lower bound with H_A = log(A/(T_A + d_A)) in place of L_α, and P^T(T < τ ≤ T + d) ≤ min{1, (T D_KL(P‖Q) + log 2)/log(A/(T + d))} (eq. 74–75).
- **Appendix A (two-state Markov chain)**: no-change class Markov(p, q), (p, q) ∈ [κ, 1 − κ]²; Jeffreys-beta mixtures of the two transition likelihoods give a test martingale M^{p,q}_{s:t} (eq. 51–52), stabilised as (1 + M)/2 (eq. 53); growth n^{−1} log M → I(r_1‖r_0) = π_{r_1}(0) kl(p_1, p_0) + π_{r_1}(1) kl(q_1, q_0) uniformly over r_0 (Proposition A.1, eq. 54–55); Corollary A.2 gives ARL and PFA validity without independence; Theorem A.3 gives delay (1 + o_P(1)) L / I*_MC and the CADD bound, PFA numerator log(1/α) + log T + 2 log log(eT) + O(1). Infimum is a two-dimensional convex problem, O(t) per evaluation.
- **Section 8, Tables 1–2**: unit-variance Gaussian shift δ at T = 500, A = 1000, 4000 replications: empirical CADD 17.3 / 11.3 / 8.1 / 5.2 for δ = 1, 1.25, 1.5, 2 versus 28.5 / 16.3 / 10.9 / 6.3 for the repeated-confidence-sequence detector of Shekhar and Ramdas (2023a), benchmark log A / I = 13.8 / 8.8 / 6.1 / 3.5. Bounded experiments (a = 0.3 → b = 0.5): point-null universal-portfolio median delay over log(A)/I_bet is 1.16 → 1.07 as A goes 10^5 → 10^20 for Bernoulli(0.5), with Beta(10,10) and two-point laws showing variance adaptivity (I_bet 0.087 vs 0.485 vs 0.506).

## Setting and assumptions
- Data: Polish space; i.i.d. in the main text, with a dependent (Markov) example in Appendix A; the validity theorems use only the restartable conditional e-process property, not independence [sahaNonpartitionedEdetectorsNonparametric2026, Sec. 1, App. A].
- Null: composite "no change", i.i.d. R for unknown R ∈ 𝒫. Alternative: one change at unknown T from unknown P ∈ 𝒫 to unknown Q ∈ 𝒫. The post-change Q is itself an admissible no-change law, so inf_R D_KL(Q‖R) = 0 and classical Lai-type lower bounds and Lorden/Pollak worst-case delay do not apply (Sec. 1).
- Measurability of the infimum over 𝒫 is assumed throughout (Sec. 2.1); in all examples the infimum is a one- or two-dimensional convex problem.
- Metrics: ARL(τ) = inf_R E^∞_R[τ]; PFA(τ) = sup_R P^∞_R(τ < ∞); CADD at fixed T (not Pollak's supremum over T); high-probability delay for PFA detectors (Sec. 1.1).
- Delay theorems are asymptotic in α ↓ 0 with a "late change" T_α such that T_α / log(1/α) → ∞ and usually log T_α = o(log(1/α)); the lower bounds show the second condition is the regime where the PFA penalty is second order.
- The general upper bound (Sec. 6) is an existence statement: the e-processes are built without knowledge of (P, Q), but the theorem does not identify them for a given 𝒫 beyond what Ram and Ramdas (2026b) provide; the concrete examples use explicit mixtures or plug-ins instead.
- Exact all-start implementations cost O(t) per objective evaluation and O(t) memory at time t (quadratic total); pruning or geometric start grids preserve validity because they lower-bound the full statistic (Secs 4, 5, App. A).

## Open questions / gaps
- Measurability of inf_{R ∈ 𝒫} Σ_s w_s M^R_{s:t} for a general nonparametric 𝒫 is assumed, not proved [sahaNonpartitionedEdetectorsNonparametric2026, Sec. 2.1].
- The general delay bound (Theorem 6.13) is existential; it does not give a recipe for the witness e-processes beyond the Ram–Ramdas REGROW construction, and the local witness basis is only verified for weakly compact classes and the Gaussian location family (Props 6.9–6.10).
- The sub-Gaussian example (Sec. 3) only attains the worst-case I = (μ − ν)²/(2σ²), not D_KL(Q‖P); whether an explicit nonparametric detector adapts to the instance rate is left to the general theory.
- Lower bounds assume a deterministic changepoint sequence and P, Q with finite KL; no minimax-over-T (Lorden/Pollak) statement is possible in this setting (Sec. 1).
- Quadratic total computation of the exact all-start detectors; pruning keeps validity but the delay cost is not quantified.
- Experiments cover only Gaussian mean shifts and bounded means; no unknown-variance or Markov simulations are reported.
