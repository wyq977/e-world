# Conditional error functions and confirmatory adaptive designs

## Definition
A conditional error function is a prespecified statistic A of the interim data with 0 ≤ A ≤ 1 and E_P[A] ≤ α under every null P; after the interim analysis any test decision ψ with E_P[ψ | A] ≤ A is allowed, including one whose second-stage design was not foreseen, and E_P[ψ] ≤ E_P[A] ≤ α follows [brannathAnytimevalidTestingEvalues2026a, eqs 3–4]. It is the device by which confirmatory adaptive designs in clinical trials (Bauer 1989; Proschan and Hunsberger 1995; Müller and Schäfer 2001, 2004) permit sample-size reassessment, treatment or endpoint selection and other unplanned changes while controlling the type I error. On the e-value scale A/α is a sequential [e-variable](e-variable.md) and ψ/A the next one, so a two-stage adaptive design and a two-stage e-value test are the same object; a multi-stage design is a sequence (A_t) with E_P[A_1] ≤ α and E_P[A_t | A_1, …, A_{t−1}] ≤ A_{t−1}, a nonnegative supermartingale, and every anytime-valid e-value test is such a design with A_t = min(αM_t, 1) [brannathAnytimevalidTestingEvalues2026a, eqs 5–6, Sec. 2.2]. The rigorous footing is a regression model for the second-stage data given interim data and design, without which conditional probabilities are defined only up to null sets and the principle can be gamed [brannathProbabilisticFoundationConfirmatory2012, Secs 3, 5–6]. In its original two-stage form, for a one-sided test of a normal mean, it is a non-decreasing function A(z_1) of the first-stage z-score with ∫ A(z)φ(z) dz = α [poschAdaptiveTwoStage1999, Sec. 1]; the general statement, for a measurable adaptation rule with countably many options, is the adaptive conditional test [liuUnifiedTheoryTwoStage2002, Thm 6].

## Key results
- **Equivalence with sequential e-values.** E_1 = A/α, E_2 = ψ/A are sequential e-values with E_1E_2 ∈ {0, 1/α}; conversely A = αE_1 and ψ = αE_1E_2, with A ≤ 1 if E_1 ≤ 1/α and ψ a randomised test if E_2 ≤ 1/(αE_1). Multi-stage: E_1 = A_1/α, E_t = A_t/A_{t−1}, M_t = A_t/α, and A_t := min(αM_t, 1) turns any sequential e-value test into a design satisfying (6) because E_P[min(αM_t, 1) | past] ≤ min(αM_{t−1}, 1) [brannathAnytimevalidTestingEvalues2026a, eq. 5, Sec. 2.2]. Per-null versions A^P_t with rejection iff all equal 1 correspond to [e-processes](e-process.md) [Remarks 1–4].
- **A catalogue, and the equivalence with combination tests.** Four designs written as A(z_1), with A = 1 for early rejection and A = 0 for early acceptance: Proschan and Hunsberger's circular function 1 − Φ(√(z²_{1−α_1} − z_1²)); Lehmacher and Wassmer's inverse-normal design 1 − Φ(√2 z_{1−α_2} − z_1), which is the conditional rejection probability of a group-sequential z-test; Bauer and Köhne's Fisher product c_{α_2}/p_1 between the boundaries, with level condition α_1 + c_{α_2}(log α_0 − log α_1) = α; Shen and Fisher's weighted design 1 − Φ((z_{1−α} − w_1z_1)/w_2), a linear conditional error function [poschAdaptiveTwoStage1999, Secs 2–5]. A combination test and a conditional error function A(p) are two ways of specifying one rejection region in the (p, q)-plane [brannathMultiplicityFlexibilityClinical2007, Sec. 2.2.2; poschAdaptiveTwoStage1999, Sec. 9]. Every one of the four can end with a final test of the pooled sample at a local level above α when the second stage is large, e.g. Bauer–Köhne whenever p_1 < c_α/α = 0.152 at α = 0.025 [poschAdaptiveTwoStage1999, Secs 2–4, 6]. The conditional power function, the same conditional rejection probability under an alternative, compares designs with a common first-stage rule and is used to choose the second-stage sample size; Fisher's product has the higher conditional power for small z_1, the inverse-normal design for large z_1, and their overall power is nearly equal [poschAdaptiveTwoStage1999, Sec. 7].
- **Conditional invariance principle.** The common principle of flexible designs: transform the second-stage statistic to a p-value q whose conditional null distribution given interim data and second-stage design is uniform, so the joint null law of (interim data, q) is invariant to the unknown adaptation rule; reject iff q ≤ A with E_H[A] ≤ α, A pivotal in the sense that its maximum null expectation can be determined [brannathMultiplicityFlexibilityClinical2007, Secs 2.1–2.2.1].
- **The measure-theoretic statement.** With interim σ-field G, a G-measurable rule g with countable range M and one outcome X_m per option, the adapted X_g = Σ_m 1{g = m}X_m inherits any conditional property E(X_m | G) = C, ≤ C or ≥ C that holds almost everywhere on {g = m} for each m (Adaptation Lemma and corollary); with p-values satisfying P(p_m ≤ C | G) ≤ C for G-measurable C this gives P(p_g ≤ C) ≤ E_H(C), the conditional error principle, for which only the independence of p_1 and p_{2m} for each fixed m is needed [liuUnifiedTheoryTwoStage2002, Sec. 2, Thm 6, Example 5]. Combination tests need more: the adapted second-stage statistic is independent of (g, Z_1) iff the Z_{2m} have the same null distribution for every option of positive probability [liuUnifiedTheoryTwoStage2002, Thm 2]. The same lemma gives unbiased adaptive estimators, adaptive pivots and confidence intervals, and shows that the pooled mean difference is biased by cov(θ̂_1, w) when the second-stage sample size depends on the first-stage effect [liuUnifiedTheoryTwoStage2002, Thms 3–5, Example 4]. Wiki's reading: for nonnegative X_m and C = 1 the corollary says a measurable choice among countably many conditional e-variables is a conditional e-variable.
- **Three ways to build A.** Combination tests: A(P_1) = sup{v : C(P_1, v) ≤ c} with early boundaries α_1 < α < α_0 and ∫A = α, e.g. Fisher's product A = min(1, c/P_1) [brannathAnytimevalidTestingEvalues2026a, Example 2, Sec. 3.1]. Conditional rejection probability principle: A^P = E_P[φ | D] for any prespecified level-α fixed-sample or group-sequential test φ at any data-chosen interim time D (Müller and Schäfer), identified with [test induction](test-induction.md) [Example 3]. Partial conditional error functions A^I_i = E_P[φ^I_i | D] for weighted Bonferroni closed tests, summed and truncated [Sec. 4].
- **Recursive combination tests.** Fill the second argument of a combination function with the p-value of another combination test run at level A_1(P_1), and so on, choosing at each stage whether to stop with the next stage or continue; valid under the sequential p-clud condition P[P_t ≤ u | P_1, …, P_{t−1}] ≤ u, with an overall p-value Q that is exactly uniform when the stage-wise p-values are; any (A_t) that is a function of p-clud p-values is such a test with C_t(P_t, v) = v/A_t, c_t = 1 [brannathAnytimevalidTestingEvalues2026a, Secs 3.1–3.2, eq. 10]; see [calibrator](calibrator.md) for the e-to-p side.
- **Exhaustion versus flexibility.** Adaptive designs are built to exhaust the level, with equality in E_P[A] ≤ α and E_P[ψ | A] ≤ A. E-value tests leave E_1E_2 free so that one can continue multiplying ([optional continuation](optional-continuation.md)), choose α or the loss after seeing the data ([post-hoc validity](post-hoc-validity.md), justified by E_P[sup_α L_α] = E_P[E_1E_2] ≤ 1), and handle composite nulls without a least favourable configuration. These emphases are complementary: a two-e-value test with a positive chance of rejecting at stage 1 is strictly conservative whenever P_0[E_1 ≥ 1/α_1] > 0 for some α_1 > α, so level flexibility "necessarily comes for the price of a strict conservatism" [brannathAnytimevalidTestingEvalues2026a, Sec. 2.1, Remark 5]. A conditional error function cannot support a data-dependent α since α is baked into it [Sec. 5.1].
- **Buying back the level.** With a known least favourable P_0 and continuous conditional null distributions, P_t = S_t(1/E_t) with S_t the conditional survival function of 1/E_t is a p-clud p-value strictly below 1/E_t with positive probability; the e-value test equals the combination test with α_{1,1} = S_1(α), C_1 = P_2/E_1, c_1 = α, which is conservative (E_0[min(αE_1, 1)] < α, eq. 12) and is uniformly improved by raising c_1 to c_1^max or α_{1,1} to the solution of α_{1,1} + E_0[min(E_1, 1)1{P_1 > α_{1,1}}] = α, stage by stage; the Fischer–Ramdas SPRT improvement is one such choice [brannathAnytimevalidTestingEvalues2026a, App. A, A.1, eq. 13].
- **Switching to a conventional test.** Starting from any level-α design φ with A = E_H(φ | interim data), an unforeseen change is allowed if the new test φ* has A* = E_H(φ* | interim data) ≤ A, and the plan is simply completed if no change is needed; lowering the conditional type I error rate can deflate but never inflate the level. So after dropping one of two treatments and changing the sample size, the conventional level-α z-test for the selected treatment s is valid whenever A*_s ≤ min(A_s, A_{1,2}); for a hierarchical test without sample-size change this holds iff the dropped higher dose had the larger interim effect, a decrease in sample size is admissible only at small interim effects and an increase only at large ones, and for the step-down Dunnett test the smaller z-test boundary and the lost chance of rejecting with the dropped arm pull in opposite directions; worked example A*_1 = 0.0496 ≤ min(0.0518, 0.0582) [brannathMultiplicityFlexibilityClinical2007, Secs 2.2.3, 3–4, eqs 1–2].
- **Flexibility is more than prespecified adaptivity.** A fixed selection rule may be valid while free switching between individually valid rules is not: always continuing with the inferior treatment cannot inflate the error, but with the Dunnett test switching to it only when both interim effects are similar and small does, because one switches exactly where the chance to reject is higher [brannathMultiplicityFlexibilityClinical2007, Secs 1, 5].
- **Multiple testing.** Flexible closed tests prespecify a conditional error function A_J with E_{H_J}[A_J] ≤ α for every intersection hypothesis and reject H_i iff q_J ≤ A_J for all J ∋ i; hypotheses dropped at the interim are accepted and q_{J∩I_2} serves for H_J; the A_J may be one function of the first-stage p-values p_J or the conditional rejection probabilities of a prespecified Dunnett or hierarchical test [brannathMultiplicityFlexibilityClinical2007, Sec. 2.3]. Partial conditional error functions A^I_i with Σ_i E_P[A^I_i] ≤ α give A^I = min(Σ_i A^I_i, 1) for each intersection, permitting dropping and reweighting of hypotheses in adaptive graphical procedures, and rejecting at the interim when A^I = 1 even if every A^I_i < 1; on the e-scale this is the weighted average E^I = Σ_i w^I_i A^I_i/(αw^I_i), and the two closed procedures reject identically; Wang's result that weighted averaging is the only admissible dependence-free merge therefore applies to conditional error functions too [brannathAnytimevalidTestingEvalues2026a, Sec. 4, eq. 11]; see [e-merging](e-merging.md), [e-closure-principle](e-closure-principle.md).
- **Why a probability model is not enough.** With A ≡ α and R_d = {Y > z_α} in a bivariate-normal two-stage trial whose correlation depends on the design, a version of P(R_{d_1} | X = x) altered on a null set containing the observed x satisfies the conditional error condition, yet the rule "d_1 iff x > z_α" rejects with probability above α by Slepian's inequality; the same move breaks the combination test. Liu, Proschan and Pledger repair this with a countable design space and a bound holding for almost all x′ in γ^{−1}(d) [liuUnifiedTheoryTwoStage2002, Sec. 2], which excludes increasing the sample size at a promising interim result when the bound holds only at the observed value [brannathProbabilisticFoundationConfirmatory2012, Sec. 4]. Their own counterexamples show what the conditions buy: a sample-size rule constant on the translates of a non-measurable set has conditional level 0.05 everywhere and no defined type I error; switching between a rank-sum and a t-test makes the stage-wise p-values dependent; with uncountably many options Z_{2s} = U·1{Z_1 ≠ s}, g = Z_1, each second-stage p-value is uniform and independent of Z_1 yet the adapted one is identically 0 [liuUnifiedTheoryTwoStage2002, Examples 10–12]. The repair that keeps that practice is a regression model F_{x,d} specified for every x and d ("regression independence", stronger than stochastic independence); under it, any adaptation rule, uncountable design space included and measurability not required, embeds into a probability space where the rejection region sits inside a set of probability α, by exhausting the conditional levels with a biased coin if necessary [brannathProbabilisticFoundationConfirmatory2012, Secs 3–6, App. A.1–A.4]. The conditional invariance principle needs the conditional p-value distribution bounded by u for every x, not almost every x [eq. 6.1].
- **Precedents for the version problem.** Bahadur and Bickel 1968 and Perlman and Wichura 1975 on substitution in conditional expectations for conventional conditional tests, Proschan and Presnell 1998 on "expecting the unexpected" from conditional expectation [brannathProbabilisticFoundationConfirmatory2012, Sec. 3].

## Disagreements / open issues
- Brannath and Fischer treat the choice between exhausting the level and keeping continuation and post-hoc flexibility as a matter of emphasis to be decided per trial; the e-value literature in this wiki treats non-exhaustion as a feature. Both agree the two cannot be had together [brannathAnytimevalidTestingEvalues2026a, Remark 5].
- Whether a regression model is necessary, not merely sufficient, for a canonical version is conjectured [brannathProbabilisticFoundationConfirmatory2012, Sec. 7].
- Liu, Proschan and Pledger hold that "for practical applications, measurability and countability hold true for any adaptation rule" [liuUnifiedTheoryTwoStage2002, Sec. 3.2]; Brannath, Gutjahr and Bauer reply that the set on which a design is chosen is unknown when the rule is not prespecified, that the almost-everywhere condition forbids adaptations justified only at the observed interim value, and that neither countability nor measurability is needed under a regression model [brannathProbabilisticFoundationConfirmatory2012, Secs 4, 6–7]. In between, Brannath, Koenig and Bauer call Liu et al. "the currently most rigorous verification" [brannathMultiplicityFlexibilityClinical2007, Sec. 2.1].
- The optimal choice of A was open in 1999: "little is known" [poschAdaptiveTwoStage1999, Sec. 9]. brannathOptimalMonotoneConditional2026 (optimal monotone conditional error functions) is in the bib and raw/ but not yet ingested.
- Brannath, Posch and Bauer 2002 (recursive combination tests), Müller and Schäfer 2001, 2004, Proschan and Hunsberger 1995 and Bauer and Köhne 1994 are primary documents and are not sources.
